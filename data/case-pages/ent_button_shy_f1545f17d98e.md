# Button Shy（米国のカードゲーム出版社）事例文 見本 2026-10-08

為替は1ドル＝150円。直した点：Shallow Regrets は2025年5月、復刻キャンペーンは2019年11月に直した。Pretense の受賞と缶バッジ時代の経歴は、確かめられていないので消した。

## 1. 一覧の1行
財布に入る18枚のカードゲームが、目標の67倍の支援を集めた

## 2. 概要
Button Shy（バトン・シャイ）は、米国ニュージャージー州のジェイソン・タグマイアが、家族や友人と営むカードゲームの出版社。二つ折りの財布に収まる、18枚以内のカードだけのゲーム（ウォレットゲーム）を、ほぼ毎月1本出している。2021年9月の新作「Unsurmountable」は、クラウドファンディングのKickstarterで目標2,000ドル（約30万円）に対し、12日間で134,553ドル（約2,018万円）を集めた。

## 3. 成功の秘訣
1. **ボードゲームの常識と逆に、財布に入る小ささを売りにした**
   普通のボードゲームは箱が大きく、1本40ドル（約6,000円）ほどする。Button Shyは財布に入るカードだけのゲームを、1本10ドル（約1,500円）で出した（本人談）。ある紹介記事は、財布を取り出すと周りが驚く点を強みと見ている。
2. **「18枚」の制限を、短くて濃いゲームを作る課題にした**
   タグマイアは18枚の形式を「設計上の課題」と呼び、狭い枠の中で最も濃い遊びを目指すと話す。枚数が少なくても、遊びの密度で買い手を満足させる狙い。
3. **作る費用を、買い手に先に出してもらう発想にした**
   タグマイアは、Kickstarterで製造費がすべてまかなえ、その後の販売分が利益になるのが理想だと話す。売れ残りの在庫を抱える危険を、出版社が負わない形にした。
4. **欲しい人が選ぶ形で、旧作を再び売った**
   売り切れた旧作のうち、どれを再び作るかを、支援者の投票で決めた。売れると分かった作品だけを作れる（推測。記事は仕組みを述べるだけで、狙いまでは書いていない）。
5. **毎月新作を受け取りたい常連を、会員にした**
   毎月1本という出し方は、新作を逃したくない熱心な客と相性がよい。その客向けに、月額の会員制度を用意した（推測。会員制度が毎月の新作と結び付いている点は記事に書かれている）。

## 4. 実際にやったこと
- 新作ごとにKickstarterを12日間ほど開き、目標額を2,000ドル（約30万円）と低く置く。目標を超えると、おまけの作品が増える仕組みを重ねた。
- 組み立て（カードを財布型ケースに入れる作業）は、タグマイアと家族・友人が手でやる。公式サイトに「手組み」と書かれている。
- 毎月の会員制度は、作り手に毎月お金を払うサービスPatreonで運営する。会員は4,390人、うち有料会員1,313人で、月18,160ドル（約272万円）が入る。月1ドル（約150円）・5ドル（約750円）・10ドル（約1,500円）・20ドル（約3,000円）の4段階があり、新作、印刷して遊べるファイル、割引が付く。
- 外部のデザイナーも使う。「18枚チャレンジ」というデザインコンテストを開き、そこから商品になった作品がある。
- 展示会に出て、その場で売る。ブログ（Substack）では新作の進み具合を伝える。

## 5. 料金
- 財布型のゲーム：1本15ドル（約2,300円）。
- 箱入りの新作：定価18ドル（約2,700円）。セール中は15ドル（約2,300円）。
- 収集用の小物「DIE Ball」：1個7ドル（約1,050円）。
- 変わった点：地元紙の記事では1本10ドル（約1,500円）だった。Kickstarterでの募集価格は、10ドル（約1,500円）から12ドル（約1,800円）へ上がった。今は財布型が15ドル（約2,300円）になっている。値上げの時期は確認できていない。

## 6. 時間順の流れ
- 2019年11月：売り切れた旧作の復刻キャンペーンを開き、50,385ドル（約756万円）、1,317人の支援を集めた。
- 2021年9月：「Unsurmountable」が、確認できた中で最大の支援を集める。
- 2025年5月：「Shallow Regrets」が119,012ドル（約1,785万円）、5,438人の支援を集める。
- 2026年4〜5月：4本のミニゲーム集が、19日間で86,888ドル（約1,303万円）を集めた。
- 2026年：ウォレットだけでなく、小売店の売り場に合わせた箱入りの新作も出し始めた。
