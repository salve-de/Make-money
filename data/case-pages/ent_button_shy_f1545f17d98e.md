# Button Shy（米国のカードゲーム出版社）事例文 見本 2026-10-08

## 1. 一覧の1行
家族と友人で営む小さな出版社が作った、クラウドファンディングで1作に約2,000万円が集まったこともある、財布に入るほど小さなカードゲーム

## 2. 概要
Button Shy は、米国の小さなカードゲームの出版社。二つ折りの財布に収まる、18枚以内のカードで遊ぶゲームだけを、ほぼ毎月1本出している。新作を作る費用は、クラウドファンディングの Kickstarter で買い手から先に集める。毎月の新作を受け取る月額の会員からも、決まった収入が入る。営むのは、ジェイソン・タグマイアと家族・友人。

## 3. 成功の秘訣
1. **ボードゲームの常識と逆に、財布に入る小ささを売りにした**
   普通のボードゲームは箱が大きく、1本40ドル（約6,000円）ほどする。Button Shyは財布に入るカードだけのゲームを、その4分の1ほどの値段で出した。財布から取り出すと周りが驚く点も、強みとして紹介されている。
2. **「18枚」の制限を、短くて濃いゲームを作る課題にした**
   タグマイアは18枚の形式を「設計上の課題」と呼び、狭い枠の中で最も濃い遊びを目指すと話す。枚数が少なくても、遊びの密度で買い手を満足させる狙い。
3. **作る費用を、買い手に先に出してもらう発想にした**
   タグマイアは、Kickstarterで製造費がすべてまかなえ、その後の販売分が利益になるのが理想だと話す。売れ残りの在庫を抱える危険を、出版社が負わない形にした。
4. **欲しい人が選ぶ形で、旧作を再び売った**
   売り切れた旧作のうち、どれを再び作るかを、支援者の投票で決めた。売れると分かった作品だけを作れる（推測）。
5. **毎月新作を受け取りたい常連を、会員にした**
   毎月1本という出し方は、新作を逃したくない熱心な客と相性がよい。その客向けに、月額の会員制度を用意した（推測）。

## 4. 実際にやったこと
- **募集は12日間ほど、目標額は低く置く**
  Kickstarter の目標は2,000ドル（約30万円）。目標を超えると、おまけの作品が増える仕組みを重ねた。
- **組み立ては、家族と友人の手作業**
  カードを財布型のケースに入れる作業を、タグマイアと家族・友人が手で行う。
- **会員制度は、Patreon で運営する**
  Patreon は、作り手に毎月お金を払うサービス。会員4,390人のうち有料は1,313人で、月18,160ドル（約272万円）が入る。会員には新作、印刷して遊べるファイル、割引が付く。
- **外部のデザイナーの作品も出す**
  「18枚チャレンジ」というデザインコンテストを開き、そこから商品になった作品がある。
- **展示会に出て、その場で売る**
  新作の進み具合は、ブログ（Substack）で伝える。

## 5. 料金
- 財布型のゲーム：1本15ドル（約2,300円）
- 箱入りの新作：18ドル（約2,700円）。セール中は15ドル（約2,300円）
- 毎月の会員：月1ドル（約150円）〜20ドル（約3,000円）の4段階
- 小物「DIE Ball」：1個7ドル（約1,050円）
- 財布型は以前、1本10ドル（約1,500円）だった。Kickstarter での募集価格も、10ドル（約1,500円）から12ドル（約1,800円）に上がった。

## 6. 時間順の流れ
- 2014年9月：最初の財布型ゲーム「Movie Plotz」の募集を始めた。
- 2019年11月：売り切れた旧作の復刻キャンペーンを開き、50,385ドル（約756万円）、1,317人の支援を集めた。
- 2021年9月：「Unsurmountable」が12日間で134,553ドル（約2,018万円）、4,756人の支援を集めた。
- 2025年5月：「Shallow Regrets」が119,012ドル（約1,785万円）、5,438人の支援を集めた。
- 2026年4〜5月：4本のミニゲーム集が、19日間で86,888ドル（約1,303万円）を集めた。
- 2026年：財布型だけでなく、小売店の売り場に合わせた箱入りの新作も出し始めた。

## お金の流れ
- 支援者 → Kickstarter：新作の先払い。例：134,553ドル（約2,018万円）
- Kickstarter → Button Shy：集まった製造費
- 有料会員 → Patreon：月1ドル（約150円）〜20ドル（約3,000円）の会費
- Patreon → Button Shy：月18,160ドル（約272万円）
- 展示会の客 → Button Shy：その場で買う。1本15ドル（約2,300円）
