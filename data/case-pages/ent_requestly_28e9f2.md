# Requestly

## 一覧の1行
副業の30分で作られ、広告なしで20万人超の開発者に広まり、年約7,200万円を稼ぐ、公開中のサイトを壊さずに直しを試せる道具

## 概要
Requestly は、ウェブ開発者が、公開中の自分のサイトに直しを入れる前に、その直しを自分の画面の中だけで試せる道具。ブラウザの Chrome に足して使う。直したプログラムを本物のサイトに差し込んで、ほかの人の画面は変えないまま動きを確かめられる。画面に出すデータを送る側の作業がまだ終わっていなくても、届くはずのデータを仮に用意して、画面づくりを先に進められる。チームで使うと1人月10ドル（約1,500円、年払い）から。

インドのサチン・ジェインが、副業の30分で最初の版を作った。広まった先は、開発者が困りごとを質問するサイト Stack Overflow と、プログラムを公開し合う場 GitHub がほぼすべてだった。20万人超の開発者、1万社超が使うまでになり、2024年度の売上は約4,000万ルピー（約7,200万円）。

## 成功の秘訣
1. **「本番サイトで自分の修正を試したい」という開発者自身の不満を、そのまま道具にした**
   サチンは、手元の JavaScript の変更を、検証用の環境を待たずに本物のサイトで確かめたかった（推測）。自分が毎日困ることだったので、最初の版を30分で作れ、使う人の悩みも外さなかった（推測）。
2. **開発者が答えを探しに来る場所に、道具を置いた**
   Stack Overflow（開発者の質問サイト）と GitHub が、集客のほぼすべてだった。広告ではなく、困った人が検索して見つける形にした（推測）。
3. **中心の部分を無料で公開して、信用を先に取った**
   核になる部分は公開し、チームで使う機能を有料にした。目先の売上より、開発者に広く使ってもらうことを先に置いた（推測）。

## 実際にやったこと
- 副業で作り始め、続けるうちに専業にした（推測）。
- Chrome の拡張に加え、パソコンで使うアプリ版も出した。サービス同士がデータをやり取りする窓口（API）の設計や試験にも使える。
- 開発者の質問に答える形で Stack Overflow と GitHub で知られ、Chrome の拡張機能の利用者が20万を超えた。
- Y Combinator と投資会社 Peak XV Partners から合わせて12.5万ドル（約1,875万円）の資金を得た。
- 買収では、価格より「ふさわしい買い手」を優先した。

## つまずきと立て直し
- 無料の拡張機能として始まったため、お金を取り始めたのは後からだった（推測）。今は無料版を置かず、月額の契約にしている。

## 料金
- チーム向けは1人月10ドル（約1,500円、年払い）、機能の多い版は1人月15ドル（約2,250円、年払い）。大企業向けは個別見積もり。
- 5人で使うと年600ドル（約9万円）。

## 時間順の流れ
- 買収より前：Y Combinator と Peak XV Partners から12.5万ドル（約1,875万円）の出資を受ける。
- 2024年度：売上は約4,000万ルピー（約7,200万円）、税引き後の利益は約140万ルピー（約252万円）。
- 2025年5月6日：テストの道具の大手 BrowserStack が買収を発表。20万人超の開発者、1万社超が使う。
- 2025年5月以降：オープンソースのまま、BrowserStack の下で続ける。
