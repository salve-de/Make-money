# Requestly

## 一覧の1行
インドの開発者が副業として30分で作ったのが始まりで、年約7,200万円を稼ぐまでに育った、公開中のサイトで自分の直しを安全に試せる道具

## 概要
Requestly は、インドの開発者サチン・ジェイン（Sachin Jain）が副業として30分で最初の版を作った、通信を書き換えて試すための Chrome 拡張機能。ウェブ開発者が本番サイトで自分の修正を試せる道具で、のちに Y Combinator（有名な起業家育成の機関）の支援を受けた。20万人超の開発者、1万社超が使うまでに広がり、2025年5月にテスト大手 BrowserStack に買収された。買収額は非公開。買収前の2024年度は、営業収入が約4,000万ルピー（約7,200万円）、税引き後の利益が約140万ルピー（約252万円）と報じられている。

## 成功の秘訣
1. **「本番サイトで自分の修正を試したい」という開発者自身の不満を、そのまま道具にした**
   サチンは、手元の JavaScript の変更を、検証用の環境を待たずに本物のサイトで確かめたかったとみられる（推測）。自分が毎日困ることだったので、最初の版を30分で作れ、使う人の悩みも外さなかった（推測）。
2. **開発者が答えを探しに来る場所に、道具を置いた**
   本人は、Stack Overflow（開発者の質問サイト）と GitHub がほぼ集客のすべてだったと語っている。広告ではなく、困った人が検索して見つける形にしたとみられる（推測）。
3. **中身を公開する「オープンコア」にして、信用を先に取った**
   核になる部分は公開し、チームで使う機能を有料にした。目先の売上より、開発者に広く使ってもらうことを先に置いたとみられる（推測）。

## 実際にやったこと
- 副業で作り始め、続けるうちに専業にしたとみられる（推測）。
- 公式は「ブラウザ上で通信を捕まえ、書き換え、模擬の応答を返す」道具として、API の設計・テストを行うデスクトップ版にも広げた。
- 開発者の質問に答える形で Stack Overflow と GitHub で知られ、Chrome の拡張機能のストアの利用が20万超に達した。
- Y Combinator と Peak XV Partners（旧 Sequoia Capital India、2023年に改称）から合わせて12.5万ドル（約1,875万円）の資金を得た。
- 買収では、価格より「ふさわしい買い手」を優先したと本人が語っている。

## つまずきと立て直し
- 拡張機能の無料の道具として始まったため、収益化は後からだったとみられる（推測）。今は無料版を置かず、30日の試用を経て月額の契約にしている（公式サイト）。

## 料金
- 今の公式サイト：Team は1人月10ドル（約1,500円、年払い）、Team Pro は1人月15ドル（約2,250円、年払い）、Enterprise は要問い合わせ。無料の枠はなく、30日の試用はカード不要で Team Pro の全機能を使える。Team を5人で使うと年600ドル（約9万円）。
- 公開当初の値段は確認できていない。
