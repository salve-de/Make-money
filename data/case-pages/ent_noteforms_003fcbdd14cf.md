# NoteForms

## 一覧の1行
Notion が外のアプリとつながれるようになった直後に4日で作られ、月約555万円を稼ぐまでになった、Notion に回答が直接入るフォーム作成サービス

## 概要
NoteForms（旧 NotionForms）は、フランス出身のジュリアン・ナウム（Julien Nahum）が2021年5月に出した、文書管理アプリ Notion のデータベースに回答を直接入れられるフォーム作成サービス。Notion が外部から使える窓口（API）を公開した直後に、4日で試作を作った。2022年11月には月の定期売上が1万4,700ドル（約220万円）、その後に3万7千ドル（約555万円）の水準まで伸びたと、Starter Story の見出しに出ている。

## 成功の秘訣
1. **相手の窓口が開いた直後に、一番乗りで「足りない部品」を作った**
   Notion が API を公開した直後に、Airtable にあるフォーム機能が Notion には無いと気づいた。最初期の Notion 拡張として出せたため、探している人に最初に見つかった（推測）。
2. **使われるほど広告になる形にした**
   利用者が作ったフォームを人に回すと、下に「Powered by NoteForms」が出る。獲得の55%超が口コミとこの経路で、広告費がかからなかった（推測）。
3. **相手に依存し過ぎる危うさを、早くから別の事業で埋めた**
   Notion が API を止めれば製品が消えるおそれを、本人が自覚していた。Notion に頼らない無料公開型のフォーム作成ソフト OpnForm を作った。コードは2022年9月に作られ、公開は2023年1月とする紹介もある（推定）。

## 実際にやったこと
- 試作は約4日で完成し、元手はサーバー代月20ドル（約3,000円）ほどだった。
- 最初の2〜3か月は無料で配った。その後、40%の生涯割引コードを出して、有料に切り替えた。
- Facebook・Reddit・Twitter の Notion 利用者の集まりで働きかけた（開発初日からの公開は推測）。Product Hunt では「今日の製品」と Maker Grant を取った。
- YouTube の動画（約1.3万回再生）、約2,000人の Facebook グループ、ヘルプ記事の整備、海外の YouTuber 12人への無償提供で広げた。
- Google 広告は月750ドル（約11万円）で試したが、採算は取れていないと述べている（2022年11月時点）。
- 開発は8年使い慣れた技術（Laravel、Vue）だけで進めた。

## つまずきと立て直し
- Notion が突然 API を止めれば、製品が消えるリスクがあった。2022年11月の取材では、Notion 以外の製品も並行して作っていると語っている。
- 2023年6月、商標への配慮で名前を NotionForms から NoteForms に変えた（推定）。
- 2024年10月に Notion が自前のフォーム機能を発表した。差が出る機能を足して対抗していると紹介されている。
- 初期は一人で、問い合わせ対応が重かった（推測）。2022年11月時点は2人体制。

## 料金
- 最初は月15ドル（約2,250円）の定額で、競合より約5割安かった。使った量で増える料金にはしなかった（推測）。
- 今の公式サイト：無料（Basic）、月20ドル（約3,000円、Pro）、月49ドル（約7,350円、Team）。年払いは2か月分割引。

## 時間順の流れ
- 2021年5月：Notion の API 公開直後に4日で作って出す。最初の2〜3か月は無料。
- 2022年11月：月の定期売上1万4,700ドル（約220万円）、有料850人、総登録2.6万人。月の費用は約6,400ドル（約96万円）。
- 2023年1月：OpnForm を公開とする紹介がある（コードは2022年9月から。推定）。
- 2023年6月：NoteForms に改名（推定）。
- 2024年10月：Notion が自前のフォーム機能を発表する。
- 2024年ごろ：月の定期売上が3万7千ドル（約555万円）。
- 今：公式サイトに13万人超が使うと表示。
