# Snipcart

## 一覧の1行
制作会社が顧客の古いサイトのために社内で作り、そのまま有料で売り出した、どんなサイトにも後から付けられる買い物かご

## 概要
Snipcart は、すでにあるサイトで物を売りたい時に、通販サイトを作り直さずに、買い物かごを後から付けられるサービス。サイトを作る開発者やデザイナーが、ページに短いコードを足し、売る商品に目印を付けるだけで、客はそのページから商品をかごに入れて買えるようになる。サイトの見た目は自由に合わせられる。料金は売上の2％で、月の売上が1,000ドル（約15万円）に満たない店は月20ドル（約3,000円）。

カナダのケベック市にあるウェブ制作会社 Spektrum で、2013年に生まれた。客の古いサイトに通販を足す必要があり、サイトの中身に触れずに済むよう、社内で作った部品が始まりだった。2013年8月に公開し、記事を書いて検索で見つけてもらうやり方で、利用者と売上を少しずつ増やした。2020年の売上は推定で約120万ドル（約1.8億円）、有料の客は約2,250社。

## 成功の秘訣
1. **通販サイトを作り直さず、今あるサイトに後から足せるようにした**
   既存の古いサイトに、HTML と JavaScript だけで買い物かごを付けられる形にした。サイト全体の作り直しや乗り換えを嫌う小さな制作現場の悩みに合った（推測）。
2. **店の主ではなく、サイトを作る開発者とデザイナーに向けた**
   通販の専用サービスが開発者に使いづらい点を埋める、という立ち位置にした。簡単に組み込め、見た目を自由に変えられることを売りにした。
3. **静的サイトの流行が来る前から、その形の作りだった**
   静的サイトは、決まったページを並べただけの簡素なサイト。最初の2年はその流行を知らなかったが、HTML と JavaScript だけで動く作りが、のちにその流れにそのまま合った。

## 実際にやったこと
- 2013年に、母体の制作会社 Spektrum の社内の新規事業として始めた。会社が時間・資金・人手を出し、開発者が社員から創業者に移った（推測）。
- 最初の試作は、顧客の古いサイトの中身に触れずに通販機能を足すため、画面側だけで動く仕組みにしたもの。
- 記事を書いて検索で見つけてもらう取り組みで、利用者と売上を少しずつ増やした。見に来た人が買うまでの割合の改善にも力を入れ、イベントでの発表は13回を超えた。
- 黒字になってからは、Facebook 広告や動画など別の集客も試せるようになった。

## つまずきと立て直し
- 母体の制作会社から完全に離れるまで約2年、黒字になるまで約3年かかった（推測）。
- 利用が増えるにつれてデータベースの負荷が問題になり、制作現場では経験しなかった最適化に取り組んだ。

## 料金
- 売上の2％の手数料。月の売上が1,000ドル（約15万円）に満たない店は、定額で月20ドル（約3,000円）。
- 試すだけなら無料。

## 時間順の流れ
- 2013年：Spektrum の社内で試作し、同年8月に公開。
- 2015年ごろ：母体から離れる（推測）。
- 2016年ごろ：黒字になる（推測）。
- 2020年：売上は推定約120万ドル（約1.8億円）、有料の顧客は推定約2,250社。
- 2021年9月：Duda に買われる。従業員は12人。
