# Snipcart

## 一覧の1行
制作会社の社内の工夫が開発者向けカートになり、年商約1.8億円と推定

## 概要
Snipcart は、カナダのケベック市にあるウェブ制作会社 Spektrum の中で2013年に生まれた、JavaScript を足して商品の印を付けるだけでどんなサイトにも買い物かごを付けられる有料のサービス。顧客の古いサイトに通販機能を足す必要から、開発者が自前で作った部品が始まりだった。2020年の売上は約120万ドル（約1.8億円）、有料の顧客は約2,250社と推定される（推定）。2021年9月に米国のウェブ制作基盤 Duda に買われた。

## 成功の秘訣
1. **通販サイトを作り直さず、今あるサイトに後から足せるようにした**
   既存の古いサイトに、HTML と JavaScript だけで買い物かごを付けられる形にした。サイト全体の作り直しや乗り換えを嫌う小さな制作現場の悩みに合った（推測）。
2. **店の主ではなく、サイトを作る開発者とデザイナーに向けた**
   自社の紹介ページは、通販の専用サービスが開発者に使いづらい点を埋めると書いている。簡単に組み込め、見た目を自由に変えられることを売りにした。
3. **静的サイトの流行が来る前から、その形の作りだった**
   最初の2年は静的サイトという流行を知らなかったが、HTML と JavaScript だけで動く作りが、のちにその流れにそのまま合った。

## 実際にやったこと
- 2013年に、母体の制作会社 Spektrum の社内の新規事業として始めた。会社が時間・資金・人手を出し、開発者が社員から創業者に移った（推測）。
- 最初の試作は、顧客の古いサイト（古い ASP 製）の中身に触れずに通販機能を足すため、画面側だけで動く仕組みにしたもの。
- 責任者によると、内容を発信する記事づくりと検索で見つけてもらう取り組みで、利用者と売上を少しずつ増やした。変換率の改善にも力を入れ、イベントでの発表は13回を超えた。
- 黒字になってからは、Facebook 広告や動画など別の集客も試せるようになった。

## つまずきと立て直し
- 母体の制作会社から完全に離れるまで約2年、黒字になるまで約3年かかったと伝えられる（推測）。
- 利用が増えるにつれてデータベースの負荷が問題になり、制作現場では経験しなかった最適化に取り組んだ。

## 料金
- 売上の2％の手数料（決済会社の手数料は別）。月の売上が1,000ドル（約15万円）に満たない店は、定額で月20ドル（約3,000円）。
- 動作を試すだけなら、クレジットカードなしで無期限に無料。

## 時間順の流れ
- 2013年：Spektrum の社内で試作し、同年8月に公開。
- 2015年ごろ：母体から離れる（約2年かかったとの記述）（推測）。
- 2016年ごろ：黒字になる（約3年かかったとの記述）（推測）。
- 2020年：売上は約120万ドル（約1.8億円）、有料の顧客は約2,250社と推定される（推定）。
- 2021年9月：Duda に買われる。従業員は12人。買収額は非公開。
