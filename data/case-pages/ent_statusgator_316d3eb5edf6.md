# StatusGator

## 一覧の1行
不具合の原因探しで丸1日を失った創業者が副業で作り、年1.5億円超を稼ぐ、他社サービスの障害を1か所にまとめて知らせるサービス

## 概要
StatusGator は、他社サービスの障害情報を1か所に集めて知らせる有料のサービス。創業者コリン・バートレットが、Facebook の API の不具合の原因を丸1日調べた経験から、2015年1月に副業として作った。2016年末は月330ドル（約5万円）の売上で、2022年秋に月2.5万ドル（約375万円）になった。今は年間の継続収入が「100万ドル（約1.5億円）台前半」（約1.5億円超）と本人が語る。

## 成功の秘訣
1. **「自分のサービスが落ちたのか、相手が落ちたのか」を切り分ける手間に目を付けた**
   使うサービスが増えるほど、障害の原因がどこにあるか分からなくなる。各社の障害情報のページを1画面に集めれば、その確認の手間が消える（推測）。
2. **公式の障害発表より早い、使う人の声の兆候を売りにした**
   現在は「障害ページは実態を隠す」という立ち位置で、公式発表の前に出る早期の警告を前に出している。
3. **他社の障害情報の集まりが、そのまま集客の入口になる**
   各サービスの障害を載せたページが検索に載り、そこから無料で使い始める人が来る。無料利用者が企業向けの契約に変わる流れもできた（推測）。

## 実際にやったこと
- 2015年1月に公開した。目標は同年6月までに月1,000ドル（約15万円）の売上。
- 集客は、検索と口コミだけが効いた。Facebook・Google 広告・Twitter も試したが効かなかったと2016年末に書いている。
- 2018年5月から共同創業者と本格的に取り組み始めた。2016〜2018年は本業の傍らの停滞期だった。
- 個別のサービスごとのページを作り、成長の9割超が検索経由になった（本人の発言）。
- 2020年ごろにマーケティング担当を雇い、検索で人を集めるだけの運用から、理想の顧客に向けた内容へ切り替えた。
- 2022年秋に、起業家向け支援 TinySeed に採択された。これが後押しとなり、既存の客を含めて価格を引き上げた。
- 無料プランは続けている。試用期間では障害が起きる保証がなく、有料の良さを見せられないため（推測）。

## つまずきと立て直し
- 2016年12月時点で有料は22人、無料は1,159人。月の売上330ドル（約5万円）から Heroku 154ドル（約2.3万円）などを引いた純益は161ドル（約2.4万円）。本人の目標は、顧問の仕事をやめられるだけの収入だった。
- その後2年ほど、共同創業者がいない兼業の状態が続いて伸びなかった（2016〜2018年）。

## 料金
- 2016年12月：月9.99ドル（約1,500円）と月19.99ドル（約3,000円）の2段階。
- 今：本人の発言では、自分で申し込む型が月72〜137ドル（約1.1〜2.1万円）、企業向けは年800ドル（約12万円）超。改定前の基本は月79ドル（約1.2万円）ほどだった。公式サイトには Business・Enterprise・教育向けがある。
- 2023年秋に価格を改定した。

## 時間順の流れ
- 2014年12月：最初のコードを書く。
- 2015年1月：公開する。春に最初の有料顧客を得る。
- 2016年12月：有料22人、月の売上330ドル（約5万円）。
- 2018年5月：共同創業者と本格的に始める。
- 2019年1月：月の継続収入1,100ドル（約16.5万円）。
- 2020年1月：月2,200ドル（約33万円）。
- 2021年1月：月7,000ドル（約105万円）。
- 2022年秋：月2.5万ドル（約375万円）。TinySeed に採択される。
- 2023年秋：価格改定。
- 2025年：年間の継続収入は100万ドル（約1.5億円）台前半。従業員は6人。
