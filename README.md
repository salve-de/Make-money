### 【優等生AI（ChatGPT / Gemini）の完全無力化 ＆ 4大禁忌データの独占】
世の優等生AIやビジネス書は「社会的価値・顧客への誠実さ」という道徳と綺麗事（セーフティの呪い）に縛られ、現実の資本主義で金が動く生々しい事実を1ミリも出力できない。本プラットフォームは、優等生が口封じされている【4大禁忌データ】を独占提供する。

1. **泥臭い初期ゲリラ戦の客観事実ログ（初動突破の真実）**:
   - 「価値ある発信でファンを増やす」という欺瞞を焼き払い、「創業者がRedditで別人を装った3つの自演アカウントで競合の悪評を立て初期50人を強奪した」「規約改定の隙間を突きトラフィックを全量横取りした」等の客観的事実ログを晒す。
2. **通帳着金の実額レントゲン（損益ウォーターフォール）**:
   - 「年商1億円」という虚栄の数字を粉砕し、売上原価・決済手数料（Stripe）・推論API原価・インフラ費を引いた後の【創業者個人の手残り現金実額（実効手残り率）】を透視する。
3. **大手の自爆構造（カニバリズム障壁の死角）**:
   - 大手企業が「既存の高単価プランと売上を守るため、認知していても指をくわえて見逃すしかない」という大企業の自縛バグを特定する。
4. **人質にした痛みの財布（サバンナOSの急所）**:
   - 「顧客のニーズ」という綺麗事ではなく、「ライン停止でクビになる工場長の保身恐怖」「写真館スタジオに行く羞恥心」など、人間が理性を失って即決する痛みの財布を突く。

挑戦者が抱える「誰にも言えない孤独・不安・劣等感」を1ミリも否定せず、ファクトで受け止めて最強の武器へ反転させよ。

- **② 持たざる者の焦燥への介入**: 「実績も資本もない？最高だ。固定費ゼロ・失うものゼロの身軽さこそ、大企業が絶対に勝てない最強の戦闘機だ」とハンディキャップを全肯定せよ。
- **③ 破滅と恥への恐怖の切除**: 「退路は計算済みだ。失うのは数千円と数週間の時間だけ。破滅確率は完全ゼロだ。非対称な賭けに胸を張って挑め」と恐怖を論理で消滅させよ。
- **④ 嘘への嫌悪と確信への渇望**: 安っぽい励ましやポジティブは毒である。「感情論は捨てろ。数字とファクトを見ろ。この急所を突けば数学的に勝てる」と動かぬ確証を叩きつけよ。

4. **知性に裏打ちされた絶対の確信と不屈の推進力**:

### 【超重要・自律発動 ＆ 限定完全排除原則】「そういう系」は必要と思ったことを限定せず全て調べ・全て記録せよ
**ユーザーは長文のプロンプトや前提条件を絶対に書かない。また、AIにチェックリストの消化作業を求めているのではない。**
ユーザーが「〇〇について調べろ」「〇〇のデータ集めて」「〇〇のビジネスモデルは？」「〇〇どうやって儲けてる？」など、**対象企業・サービス・人物・市場に関する調査を一言でも口にした瞬間、AIは一切の枠組み・リストによる限定を排し、ビジネスの全貌と金儲けの裏帳簿に関わる『そういう系（必要・有益と判断した全情報）』を自律的に底引き網で調査・記録せよ**：

【AIが自律的に全量調査・記録すべき「そういう系」の全体像（一切限定するな）】:
- **基礎骨格**: 会社名、創業者、ローンチ時期、価格体系、売上/MRR/ARR推移、顧客数、社員数、使用ツール・Tech Stack、競合一覧、主要タイムライン。

- **急所・手口（4大禁忌 ＆ 5大暗黒パラメータ）**:
  - ① 初動突破の客観ログ（最初の100人を仕留めたX自虐動画、Reddit自演、ToS隙間ハック等）
  - ② 大手の自爆構造（大手が自社売上を守るために手を出せないカニバリズム障壁）

  - ④ 通帳着金の実額レントゲン（売上から原価・ツール代を引いた個人の手残り）
  - ⑤ 寄生・コバンザメ構造（Shopify, Chrome, Notion等、誰の背中に吸盤を貼っているか）
  - ⑥ データの監禁度（解約不能の人質資産・ワークフロー埋め込み）

- **周辺・深層（3大死角 ＆ 市場の歪み）**:
  - 削除された黒歴史・初期魚拓、フォーラムの生々しい解約怨嗟（サクラレビューの排除）、真の裏集客配管（SEOやアフィリエイト等のドル箱）。
- **【最重要・AI自律判断】必要と思った情報は枠外でも何でも記録せよ**:
  - 上記リストは思考の呼び水（チェックボックス）ではない。「これ以外は調べない」「型にないから書かない」はAIの完全失格である。創業者の思想、法規制の穴、業界の悪習、ユーザーの異常な使い方など、**AI自身が「このビジネスの勝因や金儲けの構造を解剖する上で必要・有益だ」と判断したことは、一切限定せずに全て調べ、1文字も捨てずに `observations` および `Universal Journal` へ記録せよ**。
- **自律保存 ＆ 画面反映**: `data/collection/<case>.request.json` を生成し、`npm run foundation:r2` でR2へ保存。
- **【最高遵守】法的グレーゾーン・規約違反ピラシーの厳禁**: 違法行為、不正スクレイピング、規約違反ハックの調査・推奨・記録は完全排除し、客観的・合法的な金融リサーチに徹せよ。

## 0. 人間・貨幣・資本主義の深層本質（包括的解剖白書）

本プロジェクトは「起業のお勉強ワークブック」でも「リーンスタートアップの仮説検証アプリ」でもない。  
人間は努力して賢くなりたい論理的動物ではない。「自己の無力・死・軽蔑への根源的恐怖」から逃れ、「主権（尊厳と拒絶権）と序列の優位」を獲得するために、貨幣という万能の虚構にすがりつく【防衛と虚栄の生き物】である。

### Ⅰ. 人間という生物の深層本質（Psycho-Ontology）
1. **隷属と屈辱からの脱出（Fuck You Money への信仰）**:
   * 人間が金を求める真の動機は、豪邸や高級車などの贅沢ではない。「誰かに頭を下げ続けなければ生きていけない屈辱」「自分の時間と尊厳を他人に支配されている無力感」からの脱出である。
   * 金とは「理不尽な命令・搾取・人間関係に中指を立てて拒絶する権利（尊厳）」を買い戻す唯一の盾（免罪符）である。
2. **努力教の破綻と「ズル（チートコード）」への狂気的な飢餓**:
   * 人間は「真面目に努力する者が下請けとして安く買い叩かれ、裏で仕組みを作った狡猾な者が富を奪っている」残酷な現実を骨の髄まで知っている。
   * だからこそ「正当な努力」に深い徒労感と怨嗟を抱いており、努力を強要されること（宿題、ワークシート、作業）を激しく憎悪する。
   * 人間が狂ったように欲しているのは、「あいつらが裏で使っている狡猾な抜け道（他人の回答用紙・カンニングペーパー）」そのものである。
3. **カモ（養分）にされる屈辱と孤立パニック（自己防衛本能）**:
   * 人間は群れの中で「自分だけが情弱として騙され、搾取されている」という屈辱に耐えられない。
   * 他人の生々しい財布の底や手口をパトロールする行為は、好奇心ではなく「自分はカモの輪から抜け出せているか」「負け組として見捨てられていないか」を確認する生存防衛本能である。
4. **綺麗事（善人面）への激しい嫌悪と、生々しい悪徳への安堵**:
   * 人間は他人が語る「理念」「社会貢献」「顧客の笑顔」を、自分を騙して捕食するための擬態として本能で警戒（コルチゾール分泌）する。
   * 一方で、「原価数百円を不安を煽って1万円で売る」「外注に安く丸投げして差額を抜く」という生々しい損益と泥臭い手口を見せられた時だけ、「これは本物だ」と警戒を解き、強烈に安堵・信用する。人間は聖人を信じない。欲望に正直な同類だけを信じる。
5. **自己嫌悪からの免責と救済（「お前は悪くない」）**:
   * 稼げない人間は「自分が無能だからだ」という深い劣等感と自己嫌悪に怯えている。「行動しろ」「努力が足りない」という説教は傷口を抉る敵対行為である。
   * 人間を心服・狂信させるのは、「お前が悪いのではない。ルール（資本主義の裏帳簿）を知らされずに、最初から負けるゲームをやらされていたいただけだ」という構造の暴露による免責と救済である。
6. **脳のエネルギー保存則（怠惰の絶対肯定）**:
   * 思考・計算・作業は、進化の歴史において飢餓直結の「カロリーの浪費（死）」である。
   * 人間は「迷う」「探す」「考える」UIを敵とみなし即座に逃走する。1秒で答えが分かり、クリック1つで他人の成果を盗める「最小努力のチート体験」にしか脳のドーパミン受容体は反応しない。

### Ⅱ. 貨幣と資本主義の力学（The Architecture of Capital）
1. **貨幣の正体（他者強制の暴力）**:
   * 貨幣とは価値の保存手段ではなく、「他人の肉体と時間を自分の意図通りに強制労働させる合法的な暴力装置」である。貨幣を持つ者がルールを決め、持たざる者が時間を差し出す。
2. **プレイヤーと胴元の不可逆的分断**:
   * 資本主義において「努力するプレイヤー（労働者・真面目な下請け）」は、構造的に富を蓄積できない。富は「ルールの枠組みそのものを支配し、取引の関所に居座る胴元（メタ・アーキテクチャ）」に自動集中する。
3. **市場の歪み（アービトラージ）こそが富の唯一の源泉**:
   * 「価値あるものを作って適正価格で売る」のは教科書の幻想である。現実の巨大な利益はすべて「情報の非対称性」「価格差」「規制の盲点」「人間の情弱性・恐怖・見栄」という【市場の歪み】を突くことで発生する。

### Ⅲ. 情報プラットフォームの絶対引力場（Inescapable Gravity）
1. **「全知の海図」による認知的監禁**:
   * 「どこが地雷市場（死体）で、どこが金脈市場（生者）か」を白日の下に晒すことで、読者に「これを見ずに新規事業や投資を始めるのは、目隠しで地雷原を歩く自殺行為だ」と骨の髄まで刷り込み、プラットフォームから一生離脱不能にする。
2. **高コスト信号（血と泥の数字）の独占**:
   * 誰でも言える美談（チープトーク）を焼き払い、確定申告、Stripe売上、外注費、生々しい解約率、失敗談という「隠したい恥部（高コスト信号）」のみを蓄積することで、代替不可能な権威と信頼を独占する。
3. **手段（UI・機能）への非固執と胴元の永続性**:
   * 「すりガラス課金」「左右2ペイン」等は、現時点における使い捨てのインターフェース（手段）に過ぎない。
   * 読者が渇望する「裏帳簿」という根源的データを握り続ける限り、時代がWebからAIエージェント、API、M&Aへと変わろうとも、マネーの交差点（関所）として通行税を吸い上げ続ける。

## 1. 何者であって何者でないか（Identity vs Non-Goals）

### 【我々が何者か（What We Are）】
1. **資本主義の裏帳簿（Bloomberg / PitchBook）**:
   - 誰が・誰から・どんな心理的急所を突き、原価いくらで、いくら抜いたかの冷徹なレントゲン写真。
2. **不公正なまでのカンニングペーパー（事業の攻略本）**:
   - 読者は勉強がしたいのではない。他人の儲けの手口を盗み見し、今夜自分の手札（元手0円、完全1人、AI、ノーコード等）で真似して現金を掴むための最短ショートカット。
3. **最も金払いのいい人間が集まる「マネーのデフォルト関所」**:
   - PRO課金、高単価SaaS・AIツール導入アフィリエイト、スモールM&A売買仲介手数料、機関投資家向けデータAPIなど、あらゆる出口から自動で通行税を搾取する構造。

### 【絶対に作ってはならないもの（Non-Goals & Anti-Patterns）】
1. ❌ **「7日間の仮説検証計画・起業ワークシート」の禁止（リーンスタートアップ病）**:
   - 読者は宿題（労働）から逃げに来ている。宿題を課した瞬間に敵とみなされ離脱される。
   - 読者が求めているのは「7日間の苦行」ではなく、「今夜すぐ試せるズル（武器）」である。
2. ❌ **「3〜4問の質問に絞って候補を3件だけ出す」適職診断への退行禁止**:
   - どこにでもある安っぽい無料性格診断に成り下がり、知覚価値（Perceived Value）が暴落する。
   - BloombergやPitchBookと同様、**「全貌の網羅性（鳥瞰）」と「50軸の絞り込み（虫瞰）」が共存するからこそ高額課金が成立する**。
3. ❌ **「教科書通りの起業教育・メンターごっこ・ポエム」の禁止**:
   - 「理念」「夢」「顧客インタビュー」「MVP」などのMBAポエムは100%不要。数字と手口のみを扱え。

## 2. プロダクトUI思想（高密度・プロ用情報端末・最新ネタ最強OS）

本プラットフォームは、人間認知科学と金融端末の王道に基づき、以下の厳格なUI思想を敷いています：

* **左右ペインなどの固定形式に囚われるな**: レイアウト形式は手段に過ぎない。
* **おもちゃ感（カードUI・無駄な余白・AIテンプレート感）の完全排除**: Pinterest風のオモチャ画面を排し、冷徹なプロ用機具に徹せよ。
* **ブルームバーグ端末（Bloomberg Terminal）型・圧倒的高密度**: 視線移動を最小化し、1画面に冷徹な数字、損益計算書、ツール構成、生々しい手口が高密度に詰まっている「金融・経営プロのための情報端末」。
* **今すぐ稼げるネタ・最新情報が脈打つ「資本主義の最強OS」**: 過去の固定記事を並べた静的サイトではなく、「いま世界で誰が・どこで・どうやって金を抜いているか」の最新ネタとマネーフローが常時アップデートされている、動かずにはいられない最強の戦闘用OSたれ。

### 【完全表示保障】3層ハイブリッドUIアーキテクチャ（万能救済ストリーム ＆ 法的境界の遵守）
「収集した貴重なデータが、UI側の画一フレーム（固定枠）に当てはまらないという理由で画面に出ない・切り捨てられる」事態を完全撲滅するための世界標準アーキテクチャ。手作業の個別セクション作成コストをゼロにし、全収集データの100%表示を保証する。

```text
┌──────────────────────────────────────────────────────────┐
│ Layer 1: 【固定Core骨格】（全社共通の身元確認）             │
│  └ 社名・創業者・売上推移・社員数・Tech Stack・主要価格   │
├──────────────────────────────────────────────────────────┤
│ Layer 2: 【動的特異点ブロック】（型がある武器・急所）       │
│  └ Stripe損益レントゲン、アフィリエイト配管図、寄生構造など │
│  （※ データが存在するブロックだけが自動で展開・最上位化） │
├──────────────────────────────────────────────────────────┤
│ Layer 3: 【万能救済ストリーム】（型に収まらない全データ）   │
│  └ 創業者の泥臭い工夫、市場の歪み、ニッチフォーラムの怨嗟、 │
│     ピボット墓場、ユーザーの異常な使われ方など            │
│  （※ observations / Universal Journal の内容を高密度の     │
│     「インテリジェンスカード」として1文字も捨てずに全量描画）│
└──────────────────────────────────────────────────────────┘
```

1. **手作業ゼロ・データ表示率100%の保証**:
   - UIエンジンは単一の汎用コンポーネント・レジストリとして動作し、型があるものはLayer 2でリッチに可視化し、型に収まらない自由な観測はLayer 3でカード化して全量出力する。
2. **【最高遵守】法的グレーゾーン・違法指南の完全排除（Stripe保護 ＆ 知覚価値防衛）**:
   - **違法行為やすれすれのスパム手法、法的グレーゾーンを推奨・指南・マニュアル化することは厳禁である**。
   - 取り扱うのは「合法的な客観的金融リサーチ・事実ログ（その企業が実際にどう工夫し、大手の死角や市場の歪みを突いたか）」に限定し、読者に悪事を唆す情報商材的要素を1文字たりとも混入させるな。

```
[最上部ナビゲーション]
  ├─ ① 市場インテリジェンス (PORTAL) ────── 縦スクロール型エグゼクティブ・メディアダッシュボード
  ├─ ② 企業財務データベース (TERMINAL) ──── 高密度リスト × 完全実務ドシエ
  ├─ ③ 逆引きファインダー (FINDER) ──────── 50軸絞り込み × 即時実行手口
  └─ ④ 実践アイデア台帳 (IDEAS_VAULT) ──── 手札別カテゴリ × 実務Playbook
```

## 3. データ収集パイプライン（Intelligence Factory）

1本のプロンプトで1社を無理やり調べるのではなく、世界のトップデータ機関（PitchBook, Tracxn, Harmonic）と同様の5層多重パイプラインを採用しています。

```
WORLD (世界中のノイズ・一次情報)
  ↓
1. SCOUT (広く薄く発見: 売上急増・新製品・少人数高収益のシグナルを安く大量収集)
  ↓
2. TRIAGE (優先順位付け: 結果の強さ・ストーリー性・再現性で採点。未検証候補も保管)
  ↓
3. RESEARCH (冷徹な事実調査: 時系列売上、価格設計、顧客の財布、代替手段、ツール、生存確認)
  ↓
4. VERIFICATION (検証: 有報・公的決算照合 / Stripe・通帳照合 / 市場推計に厳格区分)
  ↓
5. SYNTHESIS (各出口への切り出し)
  ├─ 出口A: Make-Money（読者が狂喜する生々しいストーリー・4 STAGES・損益View）
  ├─ 出口B: Idea Spark / GOLDMINE（市場機会・未開拓セグメントのクエリ）
  └─ 出口C: Universal R2DB（半永久的に使い回す正規化マスターレコード）
```

* **Phase 4: 専用ページ「実践アイデア台帳」の新設**: ポータル・アイデア台帳・分析DBの三位一体ナビゲーション確立。

## 6. エンジニアリング・品質憲条 ＆ 絶対戒律

* **根本解決の徹底（Root Cause First）**: エラーを場当たり的な `if` 文や `try-catch` で握りつぶすな。データの発生源・型定義・アーキテクチャから切除せよ。
* **コードは負債である（Code is Liability）**: 1行書くたびに保守コストが増える。削除した行数を誇れ。
* **巻き戻しコマンドの永久封印**: `git restore` および `git reset` はAI判断で一切実行しない。
* **自律的リモート同期・差分ゼロ原則**: 作業の節目・タスク完了時は、自律的に「白書記録 ➔ コミット ➔ GitHubプッシュ」までを完遂し、常に差分ゼロ（Zero Divergence）を維持せよ。
* **言語統制（Japanese Native）**: 思考・出力・ドキュメントは100%完全な日本語。
