# GoRails 試作 第2版（追加調査の材料で作成）
印: 本人＝本人の発言／公式／第三者／推測。1ドル=150円で約。

## やり方の具体
- 開始前の1年、ブログ読者のメールを集め、初日から売る相手がいた（本人）
- 2012年8月、ブログのアンケートで講座の需要を先に確かめた（本人ブログ）
- 配備手順のメモを公開し、検索とStack Overflowから最初の月に数千人が来た（本人）
- 無料動画を隔週で出し、Reddit・Rubyflow・メール一覧で共有した（本人）
- 無料動画はYouTubeに置き、動画の配信費を抑えた（本人）
- 週1本の月額動画に替えた2日目に、14人が購読した（本人）
- 後発のHatchboxとJumpstartの最初の客は、GoRailsの会員だった（本人）

## つまずきと立て直し
- 前: 最初の講座は月2件・月約80ドル（約1.2万円）。後: 週1本の月額に替え、その年の9月に月450ドル（約6.75万円）・約45人（本人）
- 前: 2014年9月に資金が尽きかけた。後: One Monthに加わりGoRailsを続け、約1年後に月約3,500ドル（約52.5万円）（本人）
- 前: 月9ドル（約1,350円）では1本見て解約する客が多かった。後: 月19ドル（約2,850円）に上げ、その月の売上がほぼ倍になった（本人）
- 前: 最初の動画は音声が悪く文字起こしも無いと批判された。後: マイクを買い、文字起こしを付けると返した（Hacker News、第三者）

## 時間順の流れ
- 2012年8月: ブログのアンケートで需要を確かめる
- 2014年1月1日: 受託をやめ独立。数か月かけた受託が使われず燃え尽きたため。蓄えは約9か月分（本人）
- 2014年7月16日: Hacker Newsに掲載（152点・コメント55件、投稿は第三者）
- 2014年9月: 資金が尽きかけ、One Monthに就職
- 2014年12月19日: One MonthがGoRailsを買収と報道。本人は売上の25%を受け取る条件にしたと話す
- 2016年12月: Hatchbox開始。客から「Forgeのような製品を」と提案され、人気の配備手順を自動化した（本人）
- 2018年初め: GoRails単体で月約15,000ドル（約225万円）（本人）
- 2020年8月: 累計売上100万ドル（約1.5億円）、開始から約6年半（本人）
- 2021年11月: 月次定期収入6万ドル（約900万円）。開発者とサポート担当の採用を始めた（本人）

## 真似るべき戦略の核
- 売る前に、読者のメールとアンケートで需要を確かめる（根拠: 開始前1年のメール収集、2012年のアンケート）
- 人気の手順メモを、製品に変える（根拠: 人気の配備手順→Hatchbox）
- 同じ客に、次の商品を売る（根拠: 後発2製品の最初の客はGoRailsの会員）

## 出発点
- 元手は約9か月分の蓄え。共同創業者も投資もなく、1人で開始（本人）
- 開始前の月の経費は約99ドル（約1.5万円）（本人）
- 最初の無料公開は15本。最初の有料講座は39ドル（約5,850円）で、2か月に9件（本人）

## 価格の変遷
- GoRails: 月9ドル（約1,350円）で開始 → 月19ドル（約2,850円）・年190ドル（約2.85万円）
- Jumpstart: 150ドル（約2.25万円）の買い切り → 更新が続く購読へ
- Hatchbox: 最低月29ドル（約4,350円）→ サーバー1台あたり月10ドル（約1,500円）
- 古い月9ドルのまま続ける会員が、約100人いる（本人）

## 客の声
- 「月に使う9ドルで一番いい」「55か月以上購読」（公式の声のページ、選別あり）
- 「顧客です、GoRailsが続く限り使う」（Indie Hackers 投稿コメント、第三者）
- 初期の動画への指摘: 音声が悪い、文字起こしが無い、30分近くて長い（Hacker News、第三者）
- 開始時の月額に「誰だ、動画もないのに9ドルか」という悪意あるコメントが付いた（本人の回想）
