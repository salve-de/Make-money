## 1. なぜ分担を分けるのか

読者が見たいのは、世界の実在する成功商売について『何を、誰に、どう売り、最初の客をどう集め、どんな工夫で成長したか』という具体的で自然な日本語の説明である。データ形式の完全性・SHA一致・Driveの書込権限は読者価値ではない。収集AIを保存不具合で止めない。

| 担当 | 仕事 | 本人側の完成条件 |
| --- | --- | --- |
| **ChatGPT・毎時オートメーション・編集担当** | 実在事例の調査、自然な日本語で記事を執筆、追加調査と推敲、意味のある図表、出典・根拠の提供 | 記事の**全文**、主要数字・図表・出典・補助資料を読める形で納品。本文の価値を確認 |
| **Codex・システム担当** | 完成原稿の受領、必要なデータ形式への変換、非公開保存・受入、MAKEMONEYの既存UIへ組込み、実画面の検証 | 同じ記事の中身が崩れず非公開プレビューで読めると実証。格納/変換/画面証拠を提示 |
| **オーナー** | 本番掲載と事業判断 | 明示承認なしに本番・課金を動かさない |

## 2. ChatGPTから何を受け取るか

1. 実在する事業名、公式サイト、事例ID（可能であれば）と、記事タイトル・導入・主要数字。
2. 本文：**概要／仕組み／お金／集客／運営／経緯／成功の理由**の7分類＋末尾の出典。素材のない章は一般論で水増しせず、章内の文章・表・箇条書き・図解の数は柔軟。
3. 元資料URL、主要数字の対象と時点、記事に入れなかった背景や元の調査記録。製品画像の参照先と使用条件があればその情報。
4. 作成した有用な表・グラフの元数字、必要ならオリジナルSVGの実体。図表は理解を深める場合だけ。
5. 重要な注意：『103万ドルは利益ではない』『調査記録に残す』『誰でも成功できるわけではない』等の内部的な断り書き、失敗・赤字の一般論、同じ情報の複数章での重複を**読者向け原稿に追加しない**。数字を利益と誤称したり、内容を改変してまで成功談にしない。

ChatGPTによる完成品が **Markdownの全文と出典リスト**でも受け入れる。JSONやZIPの存在を前提条件にしない。受取先の仕様に合わない場合は**Codexが変換**する。出典や事実が不足して編集上の再調査が必要な箇所だけChatGPTへ戻す。
