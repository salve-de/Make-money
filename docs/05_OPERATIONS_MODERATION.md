# 投稿審査・運用設計

## 1. 最大リスク

自由投稿が宣伝文句と誇張売上で埋まり、調査者が離れること。調査者が離れると掲載価値も消える。

したがって、「誰でも投稿できる」と「何でもメインフィードに出る」を分離する。

## 2. 投稿状態

- draft — 下書き
- pending — 審査待ち
- published_unverified — 未確認で公開
- verified — 根拠確認済み
- rejected — 不採用
- disputed — 訂正・異議確認中
- archived — 古い・終了

新規投稿は検索可能な未確認枠へ出せるが、ホーム・ランキング・おすすめは審査済みだけを優先する。

## 3. 所有者確認

段階を分ける。

1. 未Claim
2. アカウントClaim申請
3. ドメインメール確認
4. DNSまたはサイト内コード確認
5. 指標接続確認
6. 文書根拠確認

所有者確認は売上確認ではない。別バッジにする。

## 4. 審査項目

### サービス

- 実在URL
- 何を提供するかが明確
- 価格または問い合わせ条件
- カテゴリー・地域・対象顧客
- 重複ページの有無
- 禁止領域、違法性、誤認表示

### Money Signal

- 金額の種類
- 期間
- payer / receiver
- URL
- 出典が数字を支えるか
- 推定なら方法と範囲
- 同じ出来事の重複

### Demand

- 誰が困るか
- 現在の代替行動
- 不足点
- 単なる願望か、具体的な利用場面か
- 支払意思の表現

## 5. ランキング保護

- 有料プロモーションは別枠
- 同一サービスの短期再投稿を制限
- 同一人物の複数アカウント投票を異常検知
- 自社関係者、競合関係者のレビュー・評価は表示を分ける
- 票数だけでなくアカウント信頼度、重複、速度を確認
- 不自然な急増は一時保留

## 6. 発掘者の評価

投稿数ではなく、次で評価する。

- 採用率
- 根拠ランク
- 訂正率
- 重複率
- 保存・参照された回数
- 後から実際に成長した比率
- 専門分野の一貫性

## 7. 訂正

削除要求だけでなく、出典付き訂正提案を受け付ける。

- 元の値
- 新しい値
- 訂正理由
- 新しい出典
- 審査者
- 変更日時

重大な誤りは表示を止めるが、履歴そのものは監査ログに残す。

## 8. 安全・法務

- 成功保証をしない
- 投資助言・金融商品の勧誘と混同させない
- 違法サービス、詐欺、権利侵害を掲載しない
- 個人の住所・電話など不要な個人情報を集めない
- 外部データの再配布権を確認する
- アフィリエイト・スポンサーを明示する
- 削除、訂正、問い合わせ窓口を用意する
