# 財務一次資料の再照合（2026-09-11）

## 判断と反映

監査対象は営業利益不一致16行（15社、Ali Abdaalの重複を含む）にPhoto AI、Clubhouse、Quibiを加えた18社。各社の一次資料を確認し、公開するレコードを再構成した。算術を合わせるために売上・経費を捏造することはしない。

元の金額は SOURCE_INSTITUTIONAL_ENTITIES に保全する。配信用 INSTITUTIONAL_ENTITIES は financial-reconciliation.ts を適用し、証明できないP&Lを除外し、実際に取得できた原通貨・期間・指標種別をEvidenceと出典付き観測へ移した。公式価格は会社売上ではなく、登録者数やGitHubスターから課金人数を推定していない。未知の金額用の数値スロットは互換契約上0だが、全て未知フラグ付きであり、実績ゼロとして表示・ランキングへ使用しない。

Photo AIの利益率80%は全事業合計、GPU費用も2製品合算。単体の利益率や原価に転用しない。Chubbiesは年次売上・原価・EBITDAを確認し、売上−原価の粗利益だけ算出した。EBITDAを営業利益や創業者手残りに変換しない。円換算のための恣意的な為替や、月平均を実際の月商とする換算も行わない。

価格ページの参照日は2026-09-11。会計期間がそれ以前の資料は、その期間を明記しており現在の実績とは扱わない。価格ページに財務がないという事実は、会社が世界中のどこにも財務を公表していない証明ではない。

## 旧自由文からの誤情報再混入を防ぐ処置

訂正対象18社の参照用projectionでは、旧戦略、価格、推論、隠れた原価、年表にある未照合の財務文も除外する。金額と無関係の文、ツール名などは保持する。出典から新たに採用したEvidence・観測は別経路で作るため、この除外対象にしない。

ツール費用、初期資本、成長率の旧数値も未確認フラグ付きにした。ツールの月額合計に未知費用が混在する場合は合計を未確認と表示する。LTV・CACの未裏付け数値も再配信しない。元のレコードは変更せず保全し、表示用の訂正と区別した。

回帰テストは、対象全社について旧自由文の通貨・利益率の再混入がないこと、ツール名が残ること、未知費用を¥0として描画しないこと、非財務の文が残ることを確認する。マッピングと変更手順は `src/platform/data/README.md` を参照。
