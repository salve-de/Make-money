# Metrics

## 1. North-star metric

**Weekly Qualified Opportunity Discoveries (WQOD)**

1週間に、ユーザーがEvidence付きOpportunityを開き、保存・フォロー・比較・外部行動のいずれかへ進んだ回数。

単純なPVより、「有用な発見が起きたか」を表す。

## 2. Activation

初回セッションで以下のうち2つ以上を達成したユーザー割合。

- Opportunity detailを2件以上開く
- Saveする
- 自分向けFilterを選ぶ
- Productへ遷移する
- MY GOLDMINEを開く

## 3. Retention

- D1 / W1 / W4 return
- Watchlist更新通知からの再訪
- 保存Opportunityの再閲覧
- Weekly digest open → return

## 4. Marketplace health

- Verified Product数
- Product page claim率
- Productあたり有効Demand connection数
- Vendor outbound click / inquiry
- Demand gapに対するProduct coverage
- Spam rejection率

## 5. Trust metrics

- A/B evidence比率
- Stale record率
- Correction率
- Claim verification latency
- 数値種別不明率
- Sponsored label violations

## 6. Monetization

- Pro conversion
- Paid retention
- Revenue per verified Signal
- Vendor paid conversion
- Vendor renewal
- Lead value reported by vendors

## 7. Guardrails

- Feed diversity
- Same vendor concentration
- Unverified content exposure
- Reported spam
- Bounce after sponsored content
- False certainty complaints
