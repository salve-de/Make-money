# Vision

## 1. 最終的に作るもの

GOLDMINE RADAR は、世界の金・需要・サービス・人を接続する **事業機会ネットワーク** である。

一般的な市場調査DBのように、検索条件を入力して数字を読むだけの製品にはしない。ユーザーが最初に触るのは、金額・期間・人数・意外性が一目で分かる発見フィードである。そこから根拠、需要、競合、参入余地、既存サービスへ進む。

## 2. ユーザーに起こしたい感情

サイト訪問後に、次の順序で感情が発生する状態を作る。

1. **驚き** — 「こんなところに金があったのか」
2. **自己接続** — 「この人にできたなら、自分にも可能性がある」
3. **時間的余地** — 「その成功は終わった話ではなく、まだ入口が残っている」
4. **所有感** — 「自分専用の金脈候補を貯めている」
5. **優位性** — 「他人より早く発見できるかもしれない」
6. **行動可能性** — 「次に確認することが具体的に分かる」

## 3. 中核命題

> 次に金持ちになる人が、他人より早く見ている情報を一か所へ集める。

「このサイトを使えば必ず億万長者になれる」とは断定しない。代わりに、成功、需要、支出、失敗、参入余地を、通常より早く・深く・自分向けに見つけられる優位性を提供する。

## 4. 戦略的ポジション

既存市場は分断されている。

- 成功事例メディア：誰が何で稼いだか
- トレンドツール：何が注目されているか
- 企業DB：誰が資金調達したか
- 政府支出DB：どこに公金が動いたか
- 製品ディレクトリ：どんなサービスがあるか
- レビューサイト：どの製品を買うべきか
- M&Aマーケット：何が売りに出ているか

GOLDMINE RADAR はこれらを、**なぜ金が動いたか／まだ誰が満たされていないか／個人がどこから入れるか** で接続する。

## 5. 長期的な防御力

単なる記事やAI要約はコピーされる。長期的な資産は以下である。

- Money Signal の時系列履歴
- Evidence の信頼度と訂正履歴
- Product・Demand・Opportunity間の関係グラフ
- 「欲しい」「払ってもよい」「作れそう」などの内部需要データ
- どのユーザーがどの機会をいつ発見したか
- 掲載者が公開する指標と所有者確認
- 成功・失敗を含む事後結果

このデータが増えるほど、単発の検索や汎用AIでは代替しにくくなる。
