## 0. 最も重要な現在地

- オーナーの最上位の経営目的は、**MAKEMONEY運営者の長期的な実利益の最大化**。そのために、読むだけの人も継続訪問・課金したくなる具体的な情報価値が必要。PVや機能数やモックの完成度自体は目的ではない。
- **直近フェーズは「既存事例を掲載する＋事例横断の共通構造・成功のエッセンス＋世界中の最新の需要・トレンド・収益機会の発見＋稼げそうなアイデアを考えたり試す」ことに集中。** 作る・公開・販売・紹介は長期構想として残すが、今ここでの実装対象からは外す。事例の個別ページから「作る」導線を追加しない。
- 「事例」は実在企業・商品が主役。「傾向」（名称は暫定）は**需要、支払う理由、検索・購買・利用・不満、市場の変化と成功の共通構造**が主役。「アイデア」は新しい案の生成・アレンジ・保存。傾向トップに個別企業名や個別成功談を主役として大量配置しない。
- **事例を分析するだけでは最近の需要は測れない。** Google Trends等の世界の検索関心、Pinterest、Etsy、顧客の声・課題、広告、求人、調達・購買、利用者調査、価格や競争の変化を複数情報源で収集する必要がある。日本の政府統計だけを主力にしない。
- **検索急増＝売上増＝潜在需要の大きさ＝参入者の利益ではない。** それぞれの指標を分け、出典・地域・観測期間・発表日・収集日と未確認条件を保持。
- 長く変わらない「需要の地図」「成功のエッセンス」と、日々変わる「市場で実際に起きたこと」「最近新しく発見した古い事例の分析」を区別。最初は最近の変化・発見を優先表示し、7・30・90日のフィルタを検討するが、架空の毎日更新や偽成長グラフは作らない。
- **画面での余計な概念説明、情緒的なコピー、ユーザー心理や制作都合の表出、教訓調の煽り見出しを禁止。** 初見で具体的な情報と利用価値が分かる配置にする。
- 既存の「事例」一覧・個別詳細の出来を基準に、**配色、情報密度、フォント、罫線のテイスト**を参考にする。ただし**傾向の画面に左右分割レイアウトを無条件でコピーしない**。事例一覧／詳細の保護範囲は既存正本に従う。
- 「比較」専用機能は不要と明示された。数値の意味、分布、外れ値、関連性を理解する分析まで全面禁止したわけではない。
- 「全部」「全候補をモックで試す」は探索段階の指示だった。**作った多種多様なモック＝仕様採用ではない。** 同様に過去の「最終仕様」「料金」「v0/外部AI/provider」も最新の事実確認・判断なしに確定扱いしない。
- **文書保存と本番承認は別。** 実課金、実送金、API有料契約、外部公開、プロダクション変更、既存収集スケジュール／権利ゲート緩和は今回許可されていない。

## 3. 判定ラベル

- **O（オーナーの明示意図／禁則）**：採用判定・モック評価を拘束。ただし実施・本番公開の許可とは別。
- **V（根拠付きの確認済み事実）**：出典・地域・時期・意味を保持し、最新情報として再検証。
- **P（提案・試作）**：価値がある候補、UIの考え方、データ連携案。実施は未承認。
- **U（未決・未検証）**：技術、ライセンス、価格、データ母集団、利用者反応、運用原価。
- **X（禁止・不採用）**：別途明示的な方針変更まで再提示・自動実行しない。
