>
> 1回の成果物は `make-money.case-batch.v1` 形式で、複数の `cases/<id>/research.json`・`article.json`・必要な `figures/*.svg`・`README.md` と全ファイルのSHA-256を含む `manifest.json` をZIPにまとめる。原稿の状態は `ready_for_review` にする。リポジトリの規約やセキュリティで書けない場合も、ダウンロード可能なZIPを納品する。他のAIが `pnpm case:batch:review -- --from <解凍したバッチ>` を使って、通常のMAKEMONEY本体UIで確認できるようにする。
