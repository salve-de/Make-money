# Trust and Moderation

## 1. Trust is the product

GOLDMINE RADARは夢と興奮を強く見せる。しかし、数字の意味を混同した瞬間に、長期資産である信用を失う。

## 2. Evidence rank

- **A**：法定開示、公的API、監査済み数値、確定成約、決済接続
- **B**：企業・本人の直接開示と補助資料
- **C**：信頼できる第三者推定
- **D**：未確認自己申告、コミュニティ投稿

Rankは出典の質を示し、成功確率を示すものではない。

## 3. Mandatory labels

- Revenue / Profit / Funding / GMV / Spend / Asking price / Estimate
- Organic / Sponsored
- Verified / Owner claimed / Unverified
- Current / Historical / Stale
- Actual / Modeled / Range

## 4. Submission flow

1. URLと基本情報を受け取る
2. 重複を検出する
3. 投稿者とProductの関係を確認する
4. ClaimsをEvidenceへ分解する
5. Pendingとして公開前審査する
6. Organic DBへ登録する
7. 有料Promotionは別オブジェクトとして作る

## 5. Moderation rules

- 同一Productの短期再投稿を制限
- 重複Productは統合
- 根拠のない大金表現は未確認表示または非公開
- 誇大な保証、違法商材、なりすまし、マルウェア、詐欺を禁止
- 競合社員・関係者のレビューは明示または除外
- 通報だけでなく、出典付き訂正を受け付ける
- 訂正履歴を消さずに保持する

## 6. Sponsored separation

有料掲載で可能なこと：

- Sponsored枠
- 対象カテゴリへの配信
- Newsletter placement
- Analytics
- Beta recruitment
- Rich profile

有料掲載で不可能なこと：

- Organic score購入
- Evidence rank購入
- 「最も有望」ラベル購入
- 他社レビュー削除
- 競合ページからの排除

## 7. Legal and operational risks

- 外部DBの再配布権
- スクレイピング規約
- 商標、ロゴ、スクリーンショット
- 個人情報とBuyer Intent
- 金融商品、賭博、投資助言に該当する表現
- 海外サービスの日本向け勧誘
- 事業売買の仲介規制と本人確認

各カテゴリ追加時に、データ利用条件と地域法令を別途確認する。
