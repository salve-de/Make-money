# 事例の図表（お金の流れ・稼ぎの推移）

2026-10-09 決定。事例の詳しい画面に出す2つの図の作り方。色・文字の大きさは [`TERMINAL_UI.md`](./TERMINAL_UI.md)（端末型）に従う。
実装は `src/features/company-inspector/ui/case-chart-options.ts`（設定を作る・試験あり）と `CasePageCharts.tsx`（描く）。

## 参考にした実例と、そこから決めたこと

参考: App Economy Insights の決算サンキー図（「How X makes money」型）、それを再現した解説（[codemeetscapital](https://codemeetscapital.substack.com/p/visualizing-financial-statements)）、FT の Visual Vocabulary（[chart-doctor](https://github.com/Financial-Times/chart-doctor/blob/main/visual-vocabulary/README.md)）と FT の軸部品 g-axis（[README](https://unpkg.com/g-axis@1.0.1/README.md)、縦軸の目盛りは右が既定）、The Economist の図の作法（縦軸の線を引かず横の目盛り線だけ残す）。

1. **文は図の外側の端に置き、帯の上には置かない。** 決算サンキー図は、左端の項目は左に、右端の項目は右に「名前（太字）＋額（細字）」を2段で書く。帯の上に文の箱を載せると帯が切れて見え、素人っぽくなる。→ 流れの文は、払うだけの客・受け取るだけの払い先など端の登場者の名前の下に書く。間に入る所（Kickstarter など）は名前の下に、そこから出る流れの文を書く。帯の上に書くのは、どこにも寄せられない時だけ。
2. **色は少なく、強調は1か所。** 実例は会社の色1色＋費用の色＋灰色程度。→ 帯はすべて同じ灰色、会社の登場者だけ白、推定の流れだけ橙（端末型の推定の色）。色の数を増やして区別しない。
3. **文字の大きさは3段だけ。** 名前 13px 太字、流れの文・軸 12px、見出しは図の外（章の見出し）。図の中に題・凡例・注記を置かない。
4. **軸は数字が読める最小限。** FT・Economist 型: 縦軸の線は引かず、横の目盛り線を薄く、目盛りの数字は右側。縦軸は必ず 0 から（伸びを大きく見せない）。横軸は年だけ。点が少ない時は各点に値、多い時は最後の点だけ。
5. **注記で言い訳しない。** 実例の図には「推定値です」「概算です」の文は無く、点や帯の形で分かるようにしてある。→ 推定は「推定」の2文字を値の横に置き、点を橙の白抜き、そこへつながる線を点線にする。それ以外の断り（本文に無い・目安・計算した・実線は〜）は出さない。

## 帯の太さ（額の無い流れ・比べられない額の扱い）

- サンキー図の帯の太さは「同じ期間の合計額」を比べる時だけ意味がある。事例の流れの文には、1人あたりの値段（月15ドルから）、1回の例（134,553ドル）、割合（利益率85%）、8年の合計などが混ざる。これを太さにすると、ありもしない比率が絵になる（嘘の図）。
- そこで **全部の流れに円の額があり、どれも同じ期間（月か年）の合計で、値段・例・割合が無く、間に入る所で入る額と出る額がほぼ合う（差が25%以内）時だけ**、額で太さを決める（`proportionalValues`）。
- それ以外は **帯の太さを1本16pxの一定** にする。太さで額を表していないので、額は文として名前の下に書く。見本の5件はどれもこの扱い。
- 一定の太さでも、登場者の高さは「つながる帯の本数」になる（会社に3本入れば3本分）。額の大小には見えない。

## 円の表記

- 図の中はドルを落として円だけにする（「月約2,250円から」）。円の換算の断りは、ページの「数字と出典」の注記にある1回で足りるので、図の中には書かない。
- 軸の目盛りは `formatYen`（約なし: 300万円・1.5億円）、点の値は約つき。

## 形と幅

- PC（描く枠が560px以上）は左から右へ。スマホ（560px未満）は上から下へ流し、一番多く横に並ぶ段の幅を等分して、各登場者を区画の真ん中に置く（端の文が切れない）。
- 文の折り返しは自分で行う（ECharts の自動の折り返しは、装飾つきの文で行が崩れるため）。金額と英語の語は途中で切らない。
- 稼ぎの推移: 同じ物を時間で追う数字は折れ線、募集のように1回ずつの出来事は棒（横軸は回ごとの日付）。2点以上ある時だけ出す。
- 1本道（客→店→会社）のように帯が少なく文が長い時は、文が収まる高さを取り、帯を上下の真ん中に置く。

## 重さ

- ECharts は図が画面に入る少し前に、使う部品（サンキー・折れ線・棒・散布・格子・SVG描画）だけを後から読み込む。図の無い事例・図まで読み進めない人には読み込まれない。
- 描画は SVG（文字がくっきり、拡大しても崩れない）。動きは付けない。
- 読み込む前と文字で読む人のために、図の中身を `aria-label` に入れる。
