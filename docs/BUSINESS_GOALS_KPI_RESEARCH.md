# Make-Money 事業目的・KPI・外部根拠（オーナー決定）

決定日・資料照合日：2026-10-09（日本時間）  
状態：**事業目的と測定すべき指標の方針は決定。実際の測定実装・数値ベースライン・KPI目標値は未確定。**  
関係文書：[OWNER_INTENT.md](OWNER_INTENT.md)、[PRODUCT_FINAL_PLAN.md](PRODUCT_FINAL_PLAN.md)、[CASE_TEXT_STANDARD.md](CASE_TEXT_STANDARD.md)

> **今回のオーナー訂正は従来の「読者価値そのものが第一目的」という書き方を置き換える。第一目的はMake-Money運営者が大きく継続的に利益を得ること。ユーザー価値・満足・再訪・習慣的利用・課金・紹介は、第一目的を実現するための不可欠な価値提供と事業成長の経路である。**  
> ただし事例の捏造、誤解を誘う成功保証、不要な滞在時間稼ぎやユーザーへの不利益を許可するものではない。読者に本当の価値を届けることが、持続的な収益の前提となる。

## 1. オーナーが達成したいこと

1. **最上位の目的：運営収益・利益の最大化。** 売上だけでなく、コスト、継続率、獲得効率、決済手数料、顧客サポート、開発運営費を差し引いた実際の利益を伸ばす。将来的に収益源を複線化し、大きく、長く稼げる事業にする。
2. **ユーザーの価値実感：** 「世の中にはこんな稼ぎ方があるのか」「自分にも何かできるかもしれない」「ここには人生を変えるヒントや機会がある」と感じる。発見・希望・期待・自己効力感を引き出し、しかも内容は事実・具体性に支えられている。
3. **継続利用：** 一度見て終わらず、繰り返し訪問し、複数事例を読み、新しい需要・稼ぎ方・機会を探し、長期にわたり価値を感じる。滞在時間は状況理解の補助であって、それ自体を最適化する目的ではない。
4. **実行と経済活動：** 事例→傾向/需要→事業検討→制作→公開→販売/紹介/広告へ進める。本当に価値を得たユーザーが課金・紹介・購入・出品することを通じて、運営利益につなぐ。
5. **継続改善：** 読者の利用・課金・制作・取引の結果を測定し、次のコンテンツと機能に反映する。アクセス数や事例数だけで事業成功と判断しない。

### 意図する心理的な流れ（実証済みの因果関係ではなく製品仮説）

「意外な成功事例に驚く」→「具体的な稼ぎ方が分かる」→「自分にも選択肢があると感じる」→「新しい情報や機会を探しに再訪する」→「継続して利用・課金・制作・販売する」→「運営利益が増える」。

**夢を感じさせる入口と、実際の価値で利用を維持する仕組みの両方が必要**。未来の成功・利益・リスクゼロを保証するような表現は採用しない。

## 2. KPIの順位（売上・利益を第一に置く）

### 2-1. 最上位KPIと重要KPI

| 優先 | KPI | 定義・計算方法 | 判断対象・頻度 |
|---|---|---|---|
| **第一** | **月次事業利益（税引前、事業単位）** | 自社の実質売上（返金・割引・取消を控除、消費税等の預り金を除外）－外部サービス利用料－決済手数料－成果報酬・紹介料－広告費－コンテンツ制作・人件費/外注費－その他実際の事業運営費。会計上の営業利益と厳密に同じとは限らないため、会計正本と調整表を持つ。 | 月次確定、週次速報。収益最大化の主判断 |
| **第二** | **実質売上・収益源別売上** | 自社会員課金＋広告・スポンサー＋紹介報酬＋Builder関連売上＋自社に帰属する市場手数料等から返金・値引きを差し引く。**出品者の商品売上総額（GMV）はMake-Money自体の売上に含めない。** | 週次/月次、部門別・顧客別・流入経路別 |
| **第三** | **有料会員の継続・解約** | 対象月に開始した有料会員の30/90/180/365日継続率と有料解約率。月額/年額プランを分け、会員の返金・支払失敗と自発的解約を区別する。 | 月次コホート（加入月別）。継続売上の質 |
| 補完 | サブスクの月次定期収益（MRR） | 月末有効の継続契約料金を月額換算して集計。年払いは12分の1、単発売上や広告、GMVは含めない。返金・一時キャンペーン・為替の扱いを固定し、現金売上と混同しない。 | 毎月末、プラン/獲得経路別 |
| 補完 | **収益成長率、利益率** | (当月－前月)÷前月（前月ゼロ時は算出不可）。月次利益率＝税引前の事業利益÷実質売上。季節性のため前年同月比と3か月移動値も併記。 | 月次 |

**補足：**「運営者が最終的に自由に使える現金」と上記「税引前事業利益」は異なる。事業資金、税金、運転資金、自己報酬や借入返済を差し引いた**オーナー可処分キャッシュ**は別指標として追う。個人の未払労働を会社の利益と混同しないよう、オーナーの運営時間・時間当たり実質利益も必要に応じて内部で確認する。

### 2-2. 運営利益へつながる先行指標

| 領域 | KPI | 定義・用途 |
|---|---|---|
| 集客 | 新規訪問者、訪問経路別の有効訪問数 | 単なる総PVでなく、検索・紹介・SNS・直接流入などの獲得経路が把握できる範囲で。 |
| 興味 | **事例一覧→事例詳細の開封率** | 一覧で該当事例が実際に表示されたセッションのうち、その事例が開かれた割合。見出し・選定が興味を生むか。 |
| 発見・価値 | **価値体験率（仮説指標）** | 初回/一定期間内に事例を読み、保存、関連事例閲覧、事業検討など、価値ある行動のいずれかを完了した利用者割合。操作だけでなく、任意の短いアンケートで「新しい稼ぎ方を発見した」「自分にも試せそうだ」を測定し照合。 |
| 深い利用 | 1人あたりの有意義な閲覧事例数、次事例閲覧率、保存率 | 大量の薄いクリックを促さず、実際の関心や継続探索を把握するための補助。 |
| 習慣・再訪 | **7日/30日再訪率**、週次/月次利用者、週次利用日数 | 定義した初回利用コホートで再訪ユーザー割合を測る。DAU/MAUは参考で、無意味な滞在や頻繁な通知を増やさない。 |
| 課金 | 無料→有料転換率、閲覧→有料導線到達率、有料登録完了率 | 分母＝所定期間に対象となったユニークユーザー。プランごとに区別。獲得チャネル別の収益貢献を確認。 |
| 解約理由 | 退会理由、返金・クレーム率、決済失敗率 | 定性的な理由も調べる。価格・価値・品質・支払い障害を分ける。 |
| 行動移行 | 事例→事業検討、事業検討→Build、Build→公開の各転換率 | 進める価値があるかと、どこで止まるかを確認。開始と**完了**を分ける。 |
| 取引 | 公開済み商品数、実取引数、購入転換率、Make-Money取り分 | 商品の掲載数だけでなく実際の成立、返金、継続売上、自社収益を優先。GMVは補助。 |
| 拡散 | 記事シェア率、紹介経由の有効登録数、紹介経由有料転換率 | シェア回数だけでなく有効な登録・課金に結びついたか。 |
| コンテンツ供給 | **公開品質を満たした事例数**、新規掲載ペース、読者行動への寄与 | 1,000件は**資産・供給量のマイルストーン**であり、事業収益KPIの代わりではない。候補数、調査件数、記事完成数、公開件数を分ける。 |

### 2-3. 利益を守る効率指標・ガードレール

| 項目 | 定義・目的 |
|---|---|
| **CAC（有料顧客獲得費用）** | 獲得活動の広告費・紹介者報酬・獲得目的の制作/外注等÷期間内の新規課金顧客数。経路別に確認。配賦不能な費用は「含めず」と明示。 |
| **顧客別貢献利益** | 顧客から得た自社売上－返金－決済手数料－生成AI/API等の顧客別変動費－紹介報酬等。無料ユーザーのAI原価も監視。 |
| **LTVとLTV/CAC** | 有料加入コホートから実際に得られた累積顧客貢献利益を優先。十分な継続期間がない間は「推計」と明示し、恣意的な無期限LTVを出さない。 |
| **回収期間** | CAC÷獲得後月次平均顧客貢献利益。データ不足時は計算しない。 |
| **返金・苦情・事例品質** | 返金率、重大誤表記、根拠不一致、権利違反、無断課金、詐欺的成功保証は成長と引き換えに許容しない。 |
| **プライバシー・運用** | 同意、匿名・仮名ID、削除・保持、権限、計測障害、公開品質、決済台帳との突合を守る。 |
| **総利用時間** | **主KPIにしない**。必要な答えに短時間で到達する利用者は成功。価値・再訪・課金につながるかとの関連を検証する補助指標。 |

**成果の因果を混同しない：**「閲覧が増えたから課金が増えた」「夢を見せたから解約率が下がった」は、比較試験または十分な追跡なしに断定しない。コンテンツ施策を評価するときは、質の低いクリック増を主成果としない。

## 3. 外部調査：2026-10-09までに確認した根拠

数値は**外部市場の調査・他社の事例**。Make-Money自身のユーザー需要、CVR、LTV、将来の売上を実測した数値ではない。調査対象、時点、地域、分母の違いを保存する。

### 3-1. 収入・起業への欲求と障害

1. **日本政策金融公庫『2025年度起業と起業意識に関する調査』**（2025年11月実施、2026年2月10日公表）。全国18〜69歳、事前調査38,017人、詳細調査2,568人。起業関心層523人の回答では、起業への関心理由が「収入を増やしたい」**62.6%**、「自由に仕事がしたい」**43.8%**、「自分が自由に使える収入が欲しい」**25.4%**。まだ起業していない理由は「自己資金が不足」**48.4%**、「失敗のリスクが大きい」**29.1%**、「ビジネスのアイデアが思いつかない」**29.0%**（複数回答）。**示唆：**「稼ぐ可能性の発見」「具体的な事業アイデア」「最初の一歩への情報」への潜在的ニーズはある。ただし日本人全体の62.6%が起業を希望するという意味ではなく、起業関心層の回答である。出典：https://www.jfc.go.jp/n/findings/pdf/kigyouishiki_260210_1.pdf （本文19～20ページ）／概要：https://www.jfc.go.jp/n/findings/pdf/topics_260210.pdf
2. **Shopify–Gallup Entrepreneurship Study**（2024年6月6日報道、米国成人45,000人超の調査）。**62%**が「雇われるより自分がボスになりたい」、起業希望者の**60%**がより稼げる可能性を起業動機として回答。米国の傾向であり、日本市場やMAKEMONEYの課金意向にそのまま当てない。出典：https://news.gallup.com/poll/645593/desire-own-boss-widily-held.aspx

### 3-2. 成功事例で生まれる期待・心理

3. **Lockwood & Kunda (1997), “Superstars and Me”**。自分に関係がある領域で、成功者の到達点が**自分にも達成可能だと感じられると励みになる**一方、到底届かないと感じると逆効果になる場合がある。**示唆：**巨大な成功だけを並べず、実際の着想、最初の顧客、何を変えたかなど「成功までの道筋」を見せる。事例を見せれば金持ちになれるという意味ではない。論文 DOI：https://doi.org/10.1037/0022-3514.73.1.91 ／書誌・要旨：https://openurl.ebsco.com/contentitem/pdh%3A1997-04812-007
4. **Berger & Milkman (2012), “What Makes Online Content Viral?”**。ニューヨーク・タイムズ記事の共有を分析。興味深さ、意外性、実用性は拡散と正の関連があり、驚きや高い覚醒度を伴う感情も共有に関係する。**示唆：**事例固有の意外な行動・結果を見出しに置く意義がある。ただしこの研究は**有料会員転換や長期継続を検証していない**。出典：https://doi.org/10.1509/jmr.10.0353

### 3-3. 「成功談や市場機会の情報」が実際に売れる例

5. **Starter Story（創業者Pat Walls、2022年10月5日公開の収支説明）**：**2022年9月売上約74,000ドル、月間訪問約150万人**。当時の売上構成は**有料会員約38%、広告・スポンサー約57%、アフィリエイト約5%**。有料会員約2,500人・会員売上約30,000ドル/月。**示唆：**成功事例メディアには会員課金以外にスポンサー・紹介収益の実例がある。2026年現在の売上・利益ではなく、Make-Moneyの達成予測値でもない。出典：https://patwalls.com/half-a-decade （2022-10-05）
6. **Trends.vc / Trends Pro（2026-10-09確認）**：**年299ドル**で160以上の市場・事業機会の調査レポート、新規レポート、事業機会を提供。**示唆：**市場機会の継続的な発掘・調査は有料で販売されている。ただし課金ユーザー数や利益の裏付けはない。出典：https://access.trends.vc/
7. **Exploding Topics Pro（2026-10-09確認）**：有料料金**月39/99/249ドル**。トレンドの追跡・分析・新興商品等を提供。**示唆：**情報を発見して終わるのではなく、検索・追跡・判断までつなぐこと自体が有料商品の構成要素。売上実績を示すものではない。出典：https://explodingtopics.com/pricing

### 3-4. なぜ有料会員は継続・解約するのか

8. **RevenueCat “State of Subscription Apps 2026”**：RevenueCat利用の**115,000超のアプリ、160億ドル超の売上、10億件超の取引**に基づく（分析対象中心は2025年）。**契約期間を通じた12か月後継続率の中央値は月額プラン8%、年額プラン28%**。モバイルアプリ中心のプラットフォームデータであり、Web事例サービスの予測には使えない。**示唆：**継続率を主KPIに置き、加入月別で測る。出典：https://www.revenuecat.com/state-of-subscription-apps
9. **RevenueCat 2025調査／2026調査**：Google Playの解約理由「十分に使わなかった」は、**2025年版でカテゴリ別32〜47%**、2026年版で**26〜40%**。調査年・対象を混同しない。**示唆：**十分な価値を体験する前の解約を減らす。出典：https://www.revenuecat.com/state-of-subscription-apps-2025 ／ https://www.revenuecat.com/state-of-subscription-apps
10. **McKinsey (2021) “Creating consumer—and business—value with subscriptions”**：消費者調査では**62%**が「内容と価格の組み合わせに価値があること」を新規購読の重要な理由に挙げた。品質とバラエティも重要な理由だった。**示唆：**夢や話題性だけでは課金は持続しない。読む・発見する・制作や販売につながる対価を明確化する。出典：https://www.mckinsey.com/capabilities/growth-marketing-and-sales/our-insights/sign-up-now-creating-consumer-and-business-value-with-subscriptions

### 3-5. 事例画面で何をどう見せるか

11. **Nielsen Norman Group (2013), “Website Reading: It (Sometimes) Does Happen”**：視線追跡で、本文の第1～4段落に少なくとも一度視線が向いた人の割合は順に**81%、71%、63%、32%**。これは精読率ではない。**示唆：**見出し・冒頭で商売の中身・実績を伝え、太字の要点＋補足で拾い読みできるようにする。MAKEMONEY自体でA/B実証した結果ではない。出典：https://www.nngroup.com/articles/website-reading/

## 4. リサーチの統合判断：事実・仮説・未検証を分ける

| 論点 | 状態 | この文書の結論 |
|---|---|---|
| 「もっと稼ぎたい」「自分で稼ぎたい」という欲求は存在する | **外部調査で裏付けあり** | 内容・集客メッセージの基礎にできる |
| 具体的な成功者の事例は、到達可能感・意欲を刺激し得る | **心理研究の根拠あり** | 大きな実績＋実際にたどった過程の両方を見せる |
| 事例/市場情報に課金する顧客と事業モデルが存在する | **競合で販売/過去の収益実績あり** | 会員課金・広告・紹介等の複合収益を検討 |
| 継続利用には継続的な価値の実感が重要 | **他分野のサブスク調査あり** | 継続・解約・価値体験を指標化する |
| 「自分も大金持ちになれるかも」という期待がMAKEMONEYのCVRを上げる | **製品仮説** | 虚偽の期待を煽らず、見出し・価値訴求を比較試験する |
| 事例1,000件で大きな利益が出る | **未検証** | コンテンツ供給目標と事業収益目標を区別 |
| 長時間・毎日使わせれば利益が増える | **未検証** | 滞在時間より価値体験、再訪、課金、実取引を優先 |

**注意：** 出典に存在する数値は、その出典の対象・年度・国の数値に限る。外部業界の割合や競合の月商をMake-Moneyの達成目標、平均値、予測値として転載しない。

## 5. 計測と実行計画（現状・実装を偽らない）

### 現在確認できたコード

- `src/lib/ops/analytics.ts` / `src/components/ops/AnalyticsLoader.tsx` はCloudflare Web Analyticsのビーコン読み込み。設定トークンが無い時と同意前には読み込まない。
- `docs/PRODUCT_FINAL_PLAN.md` には閲覧、保存、制作、公開、取引、返金、継続などをFeedbackとして扱う将来の計画がある。
- 2026-10-09時点で**上表の会員継続、利益、見出し閲覧から事例詳細への転換、価値体験率などの全指標が、本番で取得・集計できることは未確認**。この文書作成でイベント送信・BI画面・自動集計を実装したわけではない。

### 計測設計の優先順位

1. 決済、返金、請求、売上、手数料、コストを既存のStripe・D1台帳等の正本と突き合わせ、**利益・実質売上・MRR・有料加入/解約**を月次で出せるようにする。収益認識と現金収支を区別する。
2. 同意を得て、事例一覧での露出、詳細閲覧、保存、次事例閲覧、課金導線、課金完了を計測する。個人情報や公開URLの機密部分を分析イベントに載せない。
3. 事例→事業検討→Build→公開→商品購入・紹介の経路を、権限と法に沿った最小限のイベントで追えるようにする。広告/紹介の attribution は期限・重複・返金を処理する。
4. 少人数の利用者への任意の短い質問で「新しい稼ぎ方を発見できた」「自分にも試せそうと感じた」を確認し、行動指標だけで心理を決めつけない。
5. 一覧の見出し、リード、事例構成、料金と機能の見せ方を比較し、**主成果＝収益・再訪・課金や価値体験、ガードレール＝返金・不満・重大誤記**で判断する。十分な母数なしに統計的有意性を主張しない。

### レビュー頻度

- **週次：** 新規有料会員、獲得経路、無料→有料の転換、7日再訪、事例閲覧、制作導線の詰まり、障害・不満。
- **月次：** 税引前事業利益、収益源別の実質売上・費用、MRR、課金会員コホート継続/解約、CAC、返金、紹介/取引への貢献。
- **四半期：** 収益源別利益、実測したLTV/CAC、コンテンツ投資効率、商品・価格・継続の改善判断。

### 未決定のもの

- 目標利益額、現実的な達成年限、価格、有料会員数目標、獲得コスト許容額、継続率目標は**まだ決定していない**。適当な数字を入力しない。
- KPIの利用者ID、イベント名、計測の保存期間・同意表示・管理画面、どの収益を誰に配賦するかは実装設計が必要。
- 既存の会計・広告・Stripe・Web Analyticsに実際どれだけのベースラインが存在するかは未監査。確認後に目標値と予算を決める。

## 6. 今後のプロダクト判断への反映

機能やコンテンツを追加する時は、**(1) 事業利益にどう寄与するか → (2) ユーザーがなぜ価値を感じるか → (3) 再訪・課金・制作・販売のどの行動が改善するか → (4) 実測でどう確かめるか → (5) 正確性・権利・プライバシーが守られるか**を先に示す。

例えば「1,000件収集」は目的でなく、**利益に結びつくコンテンツ供給能力**の目標。「面白い見出し」は目的でなく、**関心→具体的な価値体験→継続・課金**への仮説。「長時間利用」は、利用者が時間を浪費していないことと併せて評価する診断指標。

この文書は**目的・KPI・根拠を保存した正本**であり、本番計測が既に動いているとの完了宣言ではない。
