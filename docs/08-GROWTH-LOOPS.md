# Growth Loops

## 1. Content loop

Money Signalを登録 → Opportunityへ変換 → 検索・SNSで流入 → 保存・反応 → 需要データ増加 → Opportunity精度向上 → 新しい共有コンテンツ生成。

## 2. Vendor loop

ユーザーがOpportunityを見る → 既存Productを探す → Product ownerがClaimする → 情報とEvidenceを追加 → Product pageが強くなる → 顧客が流入 → 成果が新しいMoney Signalになる。

## 3. Builder loop

Demand Gapを発見 → Builderが「作る」を宣言 → Wantを押したユーザーへ通知 → Beta user獲得 → Product公開 → 成果をDBへ戻す。

## 4. Curator loop

Curatorが新しいSignalを投稿 → 採用・保存される → Reputation上昇 → より良い情報が集まる → Curatorの公開コレクションから外部流入。

## 5. Share loop

金額、人数、期間、Evidence rankを含む共有カード → SNS・ニュースレターで表示 → 詳細へ流入 → 保存 → personalized feed改善。

## 6. SEO loop

以下をIndexable pageとして蓄積する。

- Product
- Alternatives
- Opportunity
- Demand problem
- Revenue / funding / acquisition event
- Category market map
- Person / company track record

薄いAI生成ページを量産せず、Evidenceと関係データが揃ったページだけ公開する。

## 7. Scarcity without deception

- 本当に新しく観測したSignal
- Deadlineが存在する政府公募・制度変更
- 実際に変化した競争・価格
- 一定期間のみのBeta募集

偽タイマー、偽残席、根拠のない「今しかない」は使用しない。
