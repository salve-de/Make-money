# Monetization

## 1. 原則

無料層は夢・発見・共有を最大化する。有料層は、根拠・監視・比較・優先配信・リード・時間短縮へ課金する。

## 2. Revenue streams

### A. Individual subscription

**Pro 仮説：月1,980円 / 年19,800円**

- 詳細Opportunity Brief
- 無制限保存
- Watchlist
- 変化通知
- 比較
- 高度フィルター
- Evidence履歴

### B. Research subscription

**Research 仮説：月4,980円 / 年49,800円**

- 市場マップ
- 時系列
- CSV export
- 高度なDemand/Competition分析
- Alert条件
- 公開・共有レポート

### C. Vendor promotion

- Sponsored card
- Newsletter placement
- Beta user recruitment
- Category takeover with explicit ad label
- Rich profile / case study
- Targeted promotion

Organic順位と分離する。

### D. Vendor analytics

- Views
- Saves
- Outbound clicks
- Comparison appearances
- Demand segment
- Category benchmark
- Which Opportunity generated interest

### E. Affiliate and referral

- Development tools
- SaaS
- Hosting
- Payment infrastructure
- M&A marketplace referral
- Service providers

掲載順位を報酬額で歪めない。

### F. B2B / Data

- Team workspace
- API
- Custom market monitoring
- Buyer intent aggregates
- White-label reports

## 3. Not first

- 自社エスクロー
- 成功報酬型投資仲介
- ユーザー資金を預かる取引
- 未検証の高額コンサル販売

運用・規制・信用コストが高いため後回しにする。

## 4. Unit economics hypotheses

初期検証すべき数値：

- Free → save conversion
- Save → repeat visit
- Repeat visitor → Pro trial
- Pro trial → paid
- Vendor free listing → analytics interest
- Vendor promotion CAC / lead value
- Content acquisition cost per verified Signal

価格は競合価格だけで決めず、実販売と解約理由で調整する。
