# Roadmap

## Phase 0 — Foundation

- Product strategy、PRD、data model固定
- Next.js MVP
- デモデータ
- Supabase schema
- Vercel deploy

## Phase 1 — Curated discovery

- 管理者CMS
- 50〜100件の実データ
- Evidence review workflow
- Search / filter改善
- Weekly digest
- Basic analytics

Exit criteria:

- 主要カテゴリごとに最低10件
- W1 retentionの初期値取得
- 30%以上の新規ユーザーが1件以上保存

## Phase 2 — User submission and ownership

- Auth
- Product claim
- Domain/email verification
- Submission moderation queue
- Vendor analytics
- Intent
- Correction workflow

Exit criteria:

- 掲載者自身による更新が全更新の25%以上
- Spam rejectionが運用可能
- Vendorへ測定可能なoutbound valueを提供

## Phase 3 — Demand network

- Want / willing-to-pay
- Demand pages
- Builder declaration
- Beta matching
- Opportunity Gap score
- Notification

Exit criteria:

- Demand→Product connectionが継続発生
- Beta recruitment成功事例
- Internal demand dataがrecommendationへ寄与

## Phase 4 — Paid intelligence

- Pro / Research billing
- Watch conditions
- Historical charts
- Compare workspace
- CSV export
- Team plan

Exit criteria:

- Paid retentionを確認
- 調査・監視が読み物より強い課金理由になる

## Phase 5 — Network expansion

- Curator reputation
- Public collections
- Expert marketplace
- Acquisition intent
- API / data products
- More geographies and sectors

## Deferred

- 自社M&Aエスクロー
- 投資募集
- 金融商品の直接推奨
- 決済資金の保管
