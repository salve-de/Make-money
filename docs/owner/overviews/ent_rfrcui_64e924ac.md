## 概要
Refactoring UI は、アプリやサイトを自分で作れるのに、見た目がどうしても素人っぽくなる開発者のための本。色の選び方、余白の取り方、影の付け方といった具体的な直し方が並び、読みながら自分の画面をそのまま直せる。デザインを一から勉強する本ではない。218ページの本に、解説の動画、そのまま使える画面の部品やアイコン、書体の見本が付き、買い切りで99ドル（約1.5万円）から。

開発者のアダム・ワサンと、画面デザイナーのスティーブ・ショーガーが組み、2018年12月に売り出した。売り出す前の約2年間、Twitter でデザインの小技を出し続けて読者を集めていた（推定）。これまでに3万部超が売れ、2022年9月には、4年たっても売れ続けて累計の売上が250万ドル（約3.8億円）を超えたと本人が書いた。
