## 概要
Requestly は、ウェブ開発者が、公開中の自分のサイトに直しを入れる前に、その直しを自分の画面の中だけで試せる道具。ブラウザの Chrome に足して使う。直したプログラムを本物のサイトに差し込んで、ほかの人の画面は変えないまま動きを確かめられる。画面に出すデータを送る側の作業がまだ終わっていなくても、届くはずのデータを仮に用意して、画面づくりを先に進められる。チームで使うと1人月10ドル（約1,500円、年払い）から。

インドのサチン・ジェインが、副業の30分で最初の版を作った。広まった先は、開発者が困りごとを質問するサイト Stack Overflow と、プログラムを公開し合う場 GitHub がほぼすべてだった。20万人超の開発者、1万社超が使うまでになり、2024年度の売上は約4,000万ルピー（約7,200万円）。
