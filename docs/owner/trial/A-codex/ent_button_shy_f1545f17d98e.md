# Button Shy

## 一覧の1行

街づくりも物語づくりもポケットに収め、春の新作と再版の募集で約1,430万円を集めた、小型カードゲームのシリーズ

## 概要

Button Shy は、ポケットに入れて持ち歩ける小型カードゲームを作って売る出版社。代表作の Sprawlopolis では、カードを並べて街を作る。一人でも遊べ、仲間と相談しながら街を広げることもできる。

ジェイソン・タグマイアが自主出版を続ける中で、カードと説明書を財布型のケースに収めるシリーズを始めた。新作と追加カードを売り、ゲームが届く会員企画も設けた。新作と再版をまとめた春のクラファンでは、支援約束総額が9万5,245ドル（約1,430万円）になった。

## 成功の秘訣

1. **遊びを小さくして、持ち歩ける商品にした**
   大きな箱ではなく、カードと説明書が収まる財布型のケースを使った。街づくりや物語づくりを、外へ持ち出せるゲームにした。

2. **気に入ったゲームに、遊びを足せるようにした**
   Sprawlopolis には、海辺や道路工事などを加える追加カードがある。基本作を買った後にも、同じゲームを違う条件で楽しめる商品を用意した。

3. **遊ぶ人へ直接売る道を選んだ**
   問屋を通して店に並べる方法より、客への直接販売を重視した。新作の先行募集と、毎月ゲームが届く会員企画を組み合わせた。

## 実際にやったこと

- 初期の財布型シリーズは、1企画につき500個未満の小部数で作った。ケースにはカードと説明書を一緒に収めた。
- Movie Plotz の募集では、遊んで生まれた架空の映画を猫のポスターにして公開した。同じ朝に約800人へメールも送った。その後、数時間で支援額が倍になった。
- 包装・説明書・カードの生産を始めるため、500ドル（約7万5,000円）を目標に募集すると告知した。
- 主力の新作募集を四半期ごとに変える方針を示した。一方、実験的な社内制作のゲームは、少量の手組みで続けることにした。
- 社内では企画、告知、試遊を分担し、美術と図案には社外の協力者も加わった。

## つまずきと立て直し

- 自主出版では、美術制作の遅れを経験した。クラファンが目標を超えても、企画を履行する資金が足りなくなったこともある。
- Movie Plotz の包装を紹介した記事には、反応や議論が集まった。しかし、支援額の増加には結び付かなかった。その後、実際に遊んで生まれた映画のポスターを公開した。
- 手組みに時間を取られ、箱がないと売りにくい販路もあった。主力を箱入りの量産へ移し、財布型を好む客には空のケースを追加商品として用意した。箱はケースごと収まる大きさにした。
- 海外送料の上昇と通関での差し戻しにより、直接発送できる地域を絞った。販売を続けながら、現地の提携先を探すことにした。
- 生産方法を変えた後、事務所では組み立てに使っていた時間をゲーム制作へ移した。本人は、もっと早く変えてもよかったと振り返っている。

## 料金

- 財布型ゲームの基本価格は15ドル（約2,250円）。原価と関税の負担を理由に、5年以上据え置いていた価格を引き上げた。
- 追加カードの拡張セットも、1ドル（約150円）値上げした。
- クラファンでの予約価格は、基本作が10ドル（約1,500円）。拡張込みでは最大14ドル（約2,100円）と案内した。

## 時間順の流れ

- 2007年：Button Shy 名義で、ボードゲームとカードゲームの自主出版を始める。
- 2014年9月：Movie Plotz を、持ち運べる財布型のゲームとして募集する。
- 2015年1月：財布型シリーズの第2作、Pretense の募集を予告する。
- 2024年1月：毎月新作を出し、全品を手作業で組み立てる出版社として紹介される。
- 2026年4月21日〜5月9日：新作と再版をまとめた春のクラファンを行う。
- 2026年春：主力の18枚のカードゲームを箱入りの量産へ移し、募集を四半期ごとに変える方針を示す。
- 2026年5月28日：社内の制作チームを紹介し、組み立てからゲーム制作へ仕事を移した変化を語る。
