# Pinboard

## 一覧の1行
無料の大手が削った使いやすさを守り、2024年に約3,420万円の営業利益を上げた、広告のないブックマーク保存サービス

## 概要
Pinboard は、気になった記事や後で読むページを保存して、必要な時に探せるサービス。開きっぱなしのタブを閉じても、保存したページは検索で見つかる。ページの中身も保存するプランなら、元のサイトから消えた文章やPDFも読み返せる。

マチェイ・チェグウォスキが、無料のブックマークサービス Delicious の使いにくい変更をきっかけに、副業で始めた。Delicious の先行きが不安になった時や、必要な機能が削られた時に、利用者が移ってきた。Wikipedia によると、2024年の営業利益は22万8,000ドル（約3,420万円）だった。

## 成功の秘訣
1. **無料の大手に対して、速くて使いやすい道具で勝負した**
   Delicious が機能を増やして使いにくくなる中、ページを保存して探すという基本に絞った。見た目の華やかさより、古いパソコンや遅い回線でもすぐ使えることを優先した。
2. **リンクだけでなく、消えてしまうページの中身も残した**
   自分のブックマーク先を保存しておきたいという願いが、開発のきっかけの一つだった。保存した本文まで検索できるので、記事や論文を後から探す用途にも応えた。
3. **大手が見落とした、二次創作の読者の使い方に目を向けた**
   二次創作の小説を集める人たちは、記号を使って作品を細かく分類していた。Delicious がその検索を使えなくした時も、Pinboard は同じ記号を使えた。
4. **利用者から料金を受け取り、閲覧の記録を売らずに運営した**
   広告も、利用者の行動を追う仕組みも置いていない。保存したページを他人に見せず、自分だけの資料置き場として使えることも大切にした。

## 実際にやったこと
- 試してくれる人を募り、その後に有料アカウントの販売を始めた。
- Delicious やブラウザーに保存したブックマークを取り込めるようにした。分類用のタグや非公開の設定も引き継いだ。
- ブラウザーのボタンからページを保存できるようにした。メールや外部のアプリからも追加できる。
- Delicious から利用者が押し寄せた時は、共同創業者のピーター・ガジョコフとサーバーの設定を直した。一部の機能を止めたり遅くしたりして、サイト全体の停止を避けた。
- 別のサイトでアクセス急増による停止を経験し、共用サーバーの余力を増やしていた。その備えが、Pinboard への大量の流入を受け止めた。
- 二次創作の読者に Twitter で意見を求めた。利用者からは、改善案をまとめた53ページの文書が届いた。
- 契約が切れても、利用者が自分の保存データを書き出せるようにした。

## つまずきと立て直し
- 2017年から2018年にかけて、政治活動に時間を取られ、問い合わせへの返事が滞った。利用者が減り、その後は信頼を取り戻そうとした。
- 長く使ってきた仕組みが古くなり、更新しにくくなった。2020年にはサービスを動かしたまま、プログラムとデータベースを動かす土台を更新した。
- 2025年のブログでは、大量の自動アクセスへの対策が報告された。負荷を抑えるため公開ページにもログインを求めたが、リンクを共有する利用者には不便だった。人間かどうかを確かめる画面を追加し、アカウントがなくても再び見られるようにした。
- Twitter が外部から接続するための料金を変え、連携の費用が高くなりすぎた。代わりに Bluesky と連携する案について、利用者の意見を募った。

## 料金
- 初期は一度だけ払う入会料で、開始時は約3ドル（約450円）。新しい利用者が増えるたびに、次に登録する人の料金が少しずつ上がった。
- 2010年の記事では、ページの中身を保存する追加機能は年25ドル（約3,750円）だった。
- 2015年1月、新規アカウントを買い切りから年11ドル（約1,650円）の年払いに変えた。
- 渡された公式サイトでは、基本プランは年22ドル（約3,300円）。ページの中身の保存と本文検索が付くプランは年39ドル（約5,850円）。
- 複数年をまとめて契約すると割引がある。無料体験はないが、登録後1週間は理由を問わず全額返金を受けられる。

## 時間順の流れ
- 2009年春：個人のプロジェクトとして開発を始める。
- 2009年6月：試用する人を募る。
- 2009年7月：有料アカウントの販売を始める。
- 2010年1月：副業から専業になったことが TechCrunch に紹介される。
- 2010年12月：Delicious の存続を不安視する利用者が移り、登録者が1万6,000人になる。
- 2011年9月：Delicious の変更をきっかけに、二次創作の作品を集める利用者が移ってくる。
- 2024年7月：公開から15周年を迎える。
