# Pinboard

## 一覧の1行
Yahoo の元開発者が、使っていたブックマークサービスの作り直しへの不満から作り、最も多い年には約3,900万円を売り上げた、有料のブックマーク保存サービス

## 概要
Pinboard は、見つけたウェブページをボタン1つで保存し、タグや説明を付けて、あとで検索して探し出せるブックマークサービス。広告も追跡の仕組みも無く、利用者が年22ドル（約3,300円）を払って成り立つ。年39ドル（約5,850円）のプランでは、保存したページの写しも残り、ページの中身の文字からも探せる。

Yahoo の元開発者 Maciej Cegłowski が、使っていたブックマークサービス Delicious の作り直しに不満を覚え、2009年春に個人の作品として作った。同年7月に有料で売り出し、翌2010年1月には本業になった。2010年12月、Yahoo が Delicious をやめるらしいという社内資料が流出し、会員は数週間で数千人から1万6千人に増えた。2017年の売上は25万9千ドル（約3,900万円）。

## 成功の秘訣
1. **大手の無料サービスに、有料の小さなサービスで勝てることを証明した**
   Delicious は無料で、Yahoo の資金と先行する5年があった。それでも、機能を絞った有料サービスなら十分に戦えることが分かり、本人は開始後半年の振り返りでそう述べている。
2. **競合の改悪で行き場を失った人を受け止めた**
   Delicious の作り直しに不満を持つ利用者が、乗り換え先を探していた。Pinboard はその受け皿になった。
3. **ファンフィクションを楽しむ人たちの使い方に耳を傾けた**
   彼らは Delicious に、記号を使った細かなタグで作品を整理していた。作り直しでその記号の検索が消えると、Cegłowski は Pinboard が使えると呼びかけ、足りない点を尋ねた。返ってきたのは、目次付きで53ページに及ぶ要望書だった。
4. **広告ではなく利用料で運営し、データを売らない**
   FAQ では、利用料が運営費と本人の給料を賄うので、利用者のデータが商品にならないと説明している。

## 実際にやったこと
- 画面は飾りを省いて情報を詰め込み、速さと安定を優先した。
- ブラウザに置く保存ボタンを用意し、Delicious など他サービスからブックマークを取り込めるようにした。
- Delicious の共同創業者 Peter Gadjokov が技術面を手伝った。
- 2010年12月の流出で Delicious の利用者が一斉に流れ込むと、アクセスは過去最大の10倍ほどに跳ね上がった。以前、別のサイトが CNN の記事で急に注目されて落ちた経験から、サーバーを増強してあった。そのため落ちずに乗り切り、取り込み機能など一部の機能を一時的に止めるにとどめた。
- 2017年に Delicious を3万5千ドル（約525万円）で買い取り、新規登録を止めた。利用者は保存した内容を書き出すか、Pinboard に移せる。
- 開設記念日にブログで、会員数や売上の表を公開している。

## つまずきと立て直し
- 2016年11月からは、IT 業界で働く人を集める活動の遠出が続き、サポートのメールに数週間返さないこともあった。2018年は米議会選挙の資金集めに追われ、利用者から強い不満が出た。有効な会員は2017年の2万9千人から減った。
- 本人は2017年に「逆の休暇」を取り、サイトの安定化と運用の改善に取り組み、たまった苦情に向き合った。
- 2020年は外出できない時期を使い、2009〜2010年に書いた古いコードを新しい版の PHP と MySQL に移した。動いているサイトでの作業は、演奏中のバンドに腎臓移植をするようなものだと書いている。
- 2024〜2025年には、中国発とみられる大量のボット通信がサイトを圧迫した。一部の公開ページをログイン必須にしたが、簡単な CAPTCHA を入れて、アカウントの無い人にも公開ページを戻した。

## 料金
- 2009年7月の開始時は、新規登録料が約3ドル（約450円）の1回払い。新しい会員が1人入るたびに0.1セントずつ上がった。
- 2010年1月に5.79ドル（約870円）、同年12月には9ドル（約1,350円）まで上がった。スパムを防ぐ役目も果たした。
- 2010年に、ページの写しを残す機能が年25ドル（約3,750円）で加わった。
- 2015年1月、登録料の仕組みをやめ、新規は年11ドル（約1,650円）に変えた。
- 2021年2月までに、基本が年22ドル（約3,300円）、写しを残すプランが年39ドル（約5,850円）になった。古い料金の会員には、切り替えをお願いした。
- 購入後1週間は、理由を問わず全額の返金を請求できる。無料体験は無い。
- 他の人に贈るギフトのアカウントも買える。

## 時間順の流れ
- 2009年春：Cegłowski が個人の作品として作る。
- 2009年6月：希望者に試用してもらう。
- 2009年7月：有料で売り出す。
- 2010年1月：写しを残す機能の収入で、本業にできる見通しになる。会員は1,200人。
- 2010年12月：Delicious 終了をにおわせる資料が流出し、月末までに会員が1万6千人に増える。
- 2011年：Delicious が AVOS に買われて作り直され、ファンフィクションの利用者が移ってくる。
- 2011年10月：登録会員が2万5千人（有効は1万8千人）になる。
- 2015年1月：登録料を年額制に変える。
- 2017年6月：Delicious を買い取る。
- 2017年：売上が25万9千ドル（約3,900万円）。
- 2019年：開設10周年。
- 2020年：古いコードを新しい版に移す。
- 2025年1月：ボット対策の CAPTCHA とギフトアカウントを導入する。
