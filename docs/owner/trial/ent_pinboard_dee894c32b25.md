# Pinboard

## 一覧の1行
使い慣れた Yahoo のブックマークサイトの作り直しに嫌気が差して作られ、1人の運営で最も多い年には約3,900万円を売り上げた、広告なしの有料ブックマーク保存サービス

## 概要
Pinboard は、読んだウェブのページを覚えておくためのサービス。ブラウザに付けたボタンを押すとページが保存され、タグと短いメモを添えられる。何か月も後でも、言葉で検索すれば見つかる。追加の料金を払うと、保存したページの写しも残る。元のページが消えても読めて、本文の中身まで検索できる。広告も、閲覧を追跡する仕組みもない。

2009年、マチェイ・ツェグウォフスキが、Yahoo 傘下のブックマークサイト Delicious の作り直しに不満を持ち、自分用に作り始めた。2010年12月、Delicious が終わるという噂が広がると、利用者がまとめて移ってきた。売上は2010年が11万7千ドル（約1,800万円）。最も多かったのは2017年の25万9千ドル（約3,900万円）。

## 成功の秘訣
1. **大手の無料サービスの作り直しに不満を持ち、好きだった所だけで作り直した**
   Delicious の作り直しで、便利だった所が削られたと感じていた。好きだった所だけを残し、速く軽い作りにした。
2. **無料が当たり前の中で、最初からお金を取った**
   急成長を求めるサービスや、投資を多く受けるサービスは消えやすいと考えた。利用者の支払いで支えれば長く続けられ、利用者の情報を売る必要もない。
3. **お金を取ること自体を、迷惑な投稿よけと早く来た人へのごほうびにした**
   入会金は、会員が1人増えるたびに少しずつ上がる仕組みにした。早く入った人ほど安く、迷惑な投稿をする者には割に合わない。
4. **熱心なファンの集まりを、大事な客として扱った**
   人気作品の二次創作を集めるファンは、記号を使った細かいタグで作品を整理していた。元 Delicious の担当者から、その文化の大切さを教わっていた。

## 実際にやったこと
- 2009年6月に有志に試してもらい、7月から有料で受け付けた。
- 数か月後、保存したページの写しを残す機能を有料で加えた。これで本人が暮らせるだけの稼ぎになり、本業に切り替えた。
- Delicious の共同創業者ピーター・ガジョコフを誘い、技術の面で手伝ってもらった。
- Delicious に保存していたブックマークを、ボタン1つで読み込めるようにした。
- 2010年12月、Yahoo の社内会議の資料が外に出回り、Delicious が「終わらせる」側の欄に載っていたことが知れ渡った。その日の午前中に登録が殺到し、それまでで最も多かった時より桁が1つ多いアクセスが来た。
- その少し前、本人が別に運営していたトコジラミの情報サイトが、CNN の記事で人が押し寄せて落ちていた。そのためサーバーを大きく増やしてあり、同じサーバーにいた Pinboard は殺到でも止まらなかった。本人は問い合わせに答えながら設定を直し、一部の機能は一時的に止めたり遅くしたりした。
- 数週間前に数千人だった利用者が、1万6,000人になった。
- 2011年、Delicious が別の会社に売られて作り直され、「/」の記号で検索できなくなった。本人は Twitter でファンに、Pinboard ならその記号が使えると知らせ、ほかに欲しい機能を尋ねた。ファンからは、目次付きで53ページの要望書が届き、さらに利用者が増えた。
- スマホ向けの画面、外のアプリとつなぐ仕組み、Twitter や Instapaper との連携を足した。
- サイトの作りは、目新しい技術より速さと止まらないことを優先した。
- 2017年6月、長く競ってきた Delicious を3万5千ドル（約525万円）で買い取った。

## つまずきと立て直し
- 2016年11月から、米国の選挙後に IT で働く人をまとめる活動で各地を回った。2018年は選挙の資金集めに打ち込んだ。その間、問い合わせへの返事が何週間も止まり、利用者の怒りを買った。
- 実際に使っている利用者は、2017年の2万9,000人から、2020年には1万9,000人まで減った。売上も下がり、2020年は21万2千ドル（約3,200万円）だった。
- 2017年の半ばには運営に戻り、サイトを安定させ、たまった問い合わせに答えた。2019年には、離れた利用者を取り戻そうとしていると書いている。
- 2020年、新型コロナで家にこもる間に、2009年ごろの古い土台を新しい仕組みに入れ替えた。米国や欧州の利用者が寝ている夜に、日本から作業した。
- 2024年の終わりごろ、主に中国発の機械による大量の閲覧でサイトが落ちかねなくなり、一部の公開ページをログインした人だけに絞った。2025年1月、人か機械かを見分ける確認を入れ、誰でも見られる形に戻した。
- X（旧 Twitter）の外部連携の料金が上がり、Twitter の投稿からリンクを集める機能は続けられなくなった。

## 料金
- 2009年の公開時は、1回払いの入会金で約3ドル（約450円）。会員が1人増えるごとに0.1セント上がった。
- 入会金は2010年1月に5.79ドル（約870円）、2010年12月に約9ドル（約1,350円）まで上がった。
- 公開の数か月後に加わった、ページの写しを残す機能は年25ドル（約3,750円）。
- 2015年1月、新しい会員は入会金でなく年11ドル（約1,650円）の年会費に変わった。
- 2021年2月、古い料金のままの会員に、年会費へ自分から切り替えるよう頼んだ。このときの年会費は22ドル（約3,300円）、ページの写しを残す機能付きは年39ドル（約5,850円）に上がっていた。増えた分で人を雇い、本人は新しい機能に専念するためだった。
- 何年分かをまとめて払うと割り引かれる。ほかの人に会員権を贈ることもできる。

## 時間順の流れ
- 2009年春：自分用に作り始める。
- 2009年6月：有志に試してもらう。
- 2009年7月：有料で受付を始める。
- 2010年1月：ページの写しを残す機能を加え、本業に切り替えている。利用者は1,200人。
- 2010年12月：Delicious が終わるという噂が広がり、利用者が1万6,000人になる。
- 2011年9月：別の会社に売られた Delicious が作り直され、二次創作のファンなどが移ってくる。
- 2011年10月：登録2万5,000人、うち実際に使っている利用者1万8,000人。まだ1人で運営。
- 2015年1月：入会金から年会費に変える。
- 2017年：売上が最も多い年になる。
- 2017年6月：Delicious を買い取る。
- 2017〜2018年：本人が社会活動に打ち込み、利用者が減る。
- 2020年：サイトの土台を新しくする。
- 2021年2月：古い料金の会員に、年会費への切り替えを頼む。
- 2024年7月：保存されたブックマークが2億8,800万件になる。
- 2025年1月：機械の閲覧への対策を入れ、公開ページを誰でも見られる形に戻す。
