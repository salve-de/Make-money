# Pinboard

## 一覧の1行
大手の無料サービスに「終了」の噂が流れた日に乗り換え先として登録が殺到し、最も多い年には約3,900万円を売り上げるまでに成長した、広告のない有料のブックマーク保存サービス

## 概要
Pinboard は、ネットで見つけたページを、ブラウザのボタン1つで保存しておけるサービス。保存したページにはタグや短いメモを付けておけるので、何か月もたってから「前に見たあの記事」を探し出せる。上位版では、ページの写しまで残す。元のページが消えても読め、PDFの中身まで検索できる。広告も追跡の仕組みもなく、利用者が年会費を払う。

2009年7月、マチェイ・ツェグウォフスキがルーマニアの小さな台所から1人で始めた。きっかけは、ブックマーク保存の大手 Delicious の作り直しへの不満だった。2010年12月、Delicious を持つ Yahoo の社内資料が漏れ、「終わるのでは」と騒ぎになった。乗り換え先を探す利用者が Pinboard に押し寄せた。年の売上は、最も多い2017年に25万9千ドル（約3,900万円）になった。

## 成功の秘訣
1. **大手の作り直しに不満を持つ利用者の行き場を作った**
   本人も Delicious の作り直しで便利な所が消えたと感じ、昔の使いやすさだけを残した物を作った。本人は「市場を作ってくれたのは Yahoo の経営陣だ」と振り返っている。
2. **無料が当たり前の中で、最初からお金を取った**
   払う人しか入れないので、スパムを流す者や冷やかしが寄りつかない。利用者のデータを売る必要もないので、秘密を守ることを約束できる。
3. **飾りより速さと手堅さを選んだ**
   画面は文字中心で、古いパソコンや遅い回線でも速く動く。中身の技術も、あえて目新しくない物を使った。
4. **熱心な使い手の細かい使い方に応えた**
   ファンが書いた小説を集める人たちは、記号を使った細かいタグで作品を整理していた。Delicious がその記号での検索をやめた時、Pinboard はその使い方に応えた。

## 実際にやったこと
- 2009年6月に有志に試してもらい、翌月から有料の受付を始めた。
- Delicious の創業期の一人、ピーター・ガジョコフと一緒に運営した。Pinboard という名前も彼が付けた。
- Delicious の生みの親ジョシュア・シャクターに、Delicious に似た物を作ることを認めてもらった。ページの住所の決め方や料金の形も、彼の案を取り入れた。
- Delicious から、ボタン1つでブックマークを取り込めるようにした。
- 少し前に、別のサイト（トコジラミの被害を集めるサイト）が報道で急に混んで止まった。それ以来、同じサーバーの力を必要以上に増やしてあった。そのおかげで、2010年12月に登録が殺到しても止まらなかった（推測）。
- 殺到した日は、問い合わせのメールに答えながら、サーバーの設定を急いで直した。取り込みなど一部の機能は遅くしたり止めたりした。
- Twitter や Instapaper とつなぐ機能、スマホ向けの画面、外から使うための仕組みを足した。
- ファンの集まりに Twitter で「ほかに欲しい機能は」と聞いた。すると、目次付き53ページの要望書が返ってきた。
- 毎年7月の節目に、ブックマーク数・利用者数・売上の表をブログで公開してきた。
- 2017年、ライバルだった Delicious を3万5千ドル（約525万円）で買い取った。

## つまずきと立て直し
- 2017年以降、本人が IT業界の働き手を組織する活動や、選挙の資金集めで各地を回った。その間、問い合わせのメールを何週間も放っておくことがあった。
- 活発な利用者は2017年の2万9千人から2万1千人に減り、その後は1万9千人まで落ちた。年の売上も2020年には21万2千ドル（約3,180万円）に下がった。
- 本人は旅を減らしてサイトを立て直し、たまった苦情に答えた。離れた客を取り戻そうとしている。
- 2020年、2009〜2010年に書いた古いコードを新しい版の土台へ移した。動いているサイトを止めずに移すため、作業は日本から、欧米の客が眠っている夜に進めた。
- Twitter が外部とつなぐ料金を大きく上げ、Twitter のリンクを自動で保存する機能が使えなくなった。
- 2024年の終わりごろから、人の閲覧を装って多くの接続元から押し寄せるロボットに悩まされた。一時は公開のページもログインしないと見られなくした。2025年1月に、人かどうかを確かめる簡単な問題を入れて、公開のページを戻した。

## 料金
- 始めた時は1回払いの登録料で、最初は約3ドル（約450円）。登録者が1人増えるごとに0.1セントずつ上がった。2010年1月には5.79ドル（約870円）、2010年12月末には9ドル（約1,350円）になった。
- ページの写しを残す上位版は、当初は年25ドル（約3,750円）。
- 2015年1月から、新しい利用者には年11ドル（約1,650円）の年会費にした。
- 2021年2月、年会費は年22ドル（約3,300円）、上位版は年39ドル（約5,850円）に上がった。昔の1回払いの利用者には、年会費への切り替えを頼んだ（強制ではない）。増えた収入で人を雇い、本人は機能づくりに打ち込む狙い。
- 今も同じ料金で、何年分かまとめて払うと割引になる。無料のお試しは無いが、1週間はどんな理由でも全額を返す。割引の贈り物用アカウントもある。

## 時間順の流れ
- 2009年春：Delicious の作り直しへの不満から、自分用に作り始める。
- 2009年7月9日：ルーマニアのボトシャニで公開。
- 2010年1月：上位版の収入で本業になる。活発な利用者は1,200人。
- 2010年：年の売上は11万7千ドル（約1,755万円）。
- 2010年12月16日：Yahoo の資料で Delicious が「終了」の欄に載り、登録が殺到する。
- 2010年12月末：利用者が1万6千人になる（2週間前は数千人）。
- 2011年9月：Delicious が別の会社に売られて作り直され、ファンの集まりが Pinboard へ移る。
- 2011年10月：登録者は2万5千人、うち活発な利用者は1万8千人。運営は1人のまま。
- 2015年1月：1回払いの登録料をやめ、年会費にする。
- 2017年6月：Delicious を買い取る。
- 2017年：年の売上が最も多くなる。
- 2020年：古いコードを新しい土台へ移す。
- 2021年2月：値上げ。
- 2025年1月：ロボット対策をして、公開のページを戻す。
