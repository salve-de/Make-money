# Button Shy

## 一覧の1行
財布に収まる18枚のカードゲームを手作業で組み立てて売ってきた直販の出版社が、新作4本の募集で約1,430万円を集めたボードゲーム

## 概要
Button Shy は、18枚のカードを財布の形の小さな袋に収めたボードゲームを出す出版社。たとえば Sprawlopolis は、1〜4人が1枚ずつカードを置いて街を作る協力型のゲームで、遊ぶのに15〜20分かかる。財布型の基本価格は15ドル（約2,250円）。

デザイナーの Jason Tagmire が2007年から自主出版を続け、2014年9月に初のクラウドファンディングで Movie Plotz を募集した。2026年春には新作4本に2,661人が計95,245ドル（約1,430万円）の支援を約束し、目標の10,000ドル（約150万円）を大きく超えた。

## 成功の秘訣
1. **自分たちの意図した形で仕事を進めることにこだわった**
   多くの出版社は問屋を通して店に置いてもらう。Button Shy は自分たちの意図した形で仕事を進めることを重視している。
2. **財布型の小ささで、小部数でも成り立つ形を作った**
   小さな袋に12〜20枚と説明書を収める設計で、少量生産でも採算が合うようにした。小さな出版社には難しいとされる少量の出版を、この形で成り立たせた。
3. **形を変えるときも、財布を好む客のために新しい選択肢を用意した**
   主力を箱入りにするとき、空の財布を別売りにし、箱は財布が中に入る大きさにした。

## 実際にやったこと
- 2014年9月、Movie Plotz の募集で、初日は目標の約25％、2日目は約35％だった。3日目に、遊んだ内容から作った猫の架空映画の画像を投稿し、同じ朝に約800人へ便りも送った。その直後、支援額が倍になったが、どちらが効いたかは本人にも分からないと書いている。
- 同じ募集で、小型ゲームの包装を紹介する記事を BoardGameGeek に載せた。反応は多かったが、支援の増加にはつながらなかった。
- 新作の募集時に旧作もまとめて割引し、全部を選ぶと新作が実質無料になる組み合わせも用意した。絵は以前一緒に作った Fabrice Weiss に頼み、美術代は先に払ってあった。
- 2026年、主力を量産の箱入りにし、浮いた時間をゲーム作りに回した。社内の企画制作は3人で、事務所には全部で6人いる。
- 18枚のゲームの募集を四半期ごとにする方針を決めた。間の時期には、サイコロを客が用意し説明書をオンラインに置く少量の新シリーズを手組みで出す構想を進めている。

## つまずきと立て直し
- 初期の募集では、目標を超える支援を集めても企画を履行する資金が足りなくなる失敗をした。製品の美術の遅れも失敗として挙げている。
- 2026年春、手組みに時間がかかり、箱がないと売りにくい販路もあった。そこで主力を箱入りにしたが、財布型を好む客から不満が届いた。そこで空の財布を別売りにし、箱を財布が入る大きさにした。
- 海外送料が翌週8％上がることになり、その前に募集の送料として17,000ドル（約255万円）を集めていた。一部の地域からは郵便物がまとめて差戻され、約500ドル（約7.5万円）の損になった。そこで直送を一部の地域に絞り、海外の提携先を探している。カナダ向けの対応を確定できた。

## 料金
- 財布型は15ドル（約2,250円）に値上げし、拡張は1ドル（約150円）上げた。5年以上値上げしていなかった。
- クラウドファンディングの予約は1作10ドル（約1,500円）で、拡張込みで最大14ドル（約2,100円）。
- 募集中は公式サイトで使える15％引きのコードを出す。ニュージャージー州の店では全作10ドル（約1,500円）。黒い金曜日には25％引きのコードがある。

## 時間順の流れ
- 2007年：Button Shy の名で自主出版を始める。
- 2013年：自主出版の失敗談を話す登壇を予定する。
- 2014年9月：Movie Plotz を目標1,000ドル（約15万円）で募集する。
- 2026年4月21日〜5月9日：春の新作4本を募集し、95,245ドル（約1,430万円）を集める。
- 2026年5月28日：社内の企画制作チームを紹介する。
