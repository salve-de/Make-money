# Button Shy

## 一覧の1行
小さなゲームの包装の悩みを財布のようなビニールのケースで解き、新作4本のクラファンで約1,430万円を集めた、ポケットに入るカードゲームのシリーズ

## 概要
Button Shy は、18枚ほどのカードだけで遊べる小さなゲームを出す、アメリカの出版社。カードは財布のようなビニールのケースに入っていて、ポケットに入れて持ち歩ける（2026年からは主力を箱入りに変えた）。人気作の Sprawlopolis は、1〜4人が手札を1枚ずつ出し合い、力を合わせて街を作るゲームで、15〜20分で遊べる。

ゲーム作家のジェイソン・タグマイアが、2007年から Button Shy の名で自主出版を始めた。問屋を通さず、客へ直接届けてきた。2014年に、財布型のケースに入れたシリーズを始めた。2024年の時点では毎月1作の新作を出し、すべて手で組み立てていた。2026年春には新作4本をまとめたクラファンで、2,661人から9万5,245ドル（約1,430万円）を集めた。

## 成功の秘訣
1. **小さなゲームの包装の悩みを、財布型のケースで解いた**
   小さなゲームは包装が悩みの種だった。ボードゲームを少ない数で作るのは、たいてい割に合わない。ロゴ入りのビニールのケースなら、カードと説明書が収まり、500個に満たない少ない数でも作れる。
2. **問屋を通さず、自分たちで客へ直接届けると決めた**
   ふつうの出版社は問屋を通して店に並べる。Button Shy は、作るところから届けるところまでを自分たちで受け持つやり方を選んだ。
3. **18枚という同じ形で、作品を次々に並べた**
   どの作品も同じ財布型のシリーズとして出し、2024年には毎月1作の新作を出していた。ほかの作家にも、このケースで遊べるゲームを作らないかと呼びかけた。

## 実際にやったこと
- 2014年、Movie Plotz をクラファンで出した。目標は1,000ドル（約15万円）で、財布型のケースと折りたたんだ説明書を作る費用にあてた。
- 集まった額は、初日に目標の約25％、2日目に約35％だった。ボードゲーム好きが集まるサイト BoardGameGeek に包装の工夫を書いた記事は話題になったが、支援は増えなかった。
- 3日目、遊んだ中で生まれた「猫を使った架空の映画」のポスターを載せた。同じ朝、約800人にお知らせのメールも送り、数時間で支援額が倍になった。本人は、どちらが効いたかは分からないと書いている。
- 2015年の Pretense の募集では、旧作を割り引いて一緒に売る組み合わせを用意した。全作品をまとめて買うと、Pretense が実質ただになる。
- Pretense の絵は、以前に別の作品で組んだフランスの絵描きファブリス・ヴァイスに頼んだ。
- 人気作 Sprawlopolis には、怪獣が街を壊すカードや海岸のカードなど、後から足せる拡張を複数出している。
- 毎月ゲームが郵便で届く会員制を、Patreon で用意している。
- 2026年、主力シリーズは手で組み立てるのをやめ、工場で量産する箱入りに変えた。財布型を好む客には、空のケースを追加の品として売り、箱はケースごと入る大きさにした。
- 手で組み立てていた時間を、ゲームを作る時間に回した。本人は「もっと早く変えればよかった」と振り返っている。

## つまずきと立て直し
- 2013年までに、絵の遅れや、クラファンで目標を超えたのに届けるお金が足りなくなる失敗を経験した。本人は、この失敗を自主出版を考える人に向けて話す登壇を案内した。
- 手で組み立てる作業が重くなり、箱が無いと売りにくい売り場もあった。2026年に量産の箱へ移ったが、財布型を惜しむ声も届いた。空のケースを別に売ることで、両方の客に応えた。
- 海外への送料が上がり続け、EU では国境で受け取りを断られた荷物がまとめて戻ってきた。この1回で約500ドル（約7.5万円）を失った。
- クラファンで送料を1万7,000ドル（約255万円）集めた直後に、海外送料が8％上がると決まった。海外へ直接送る地域を絞り、現地で売ってくれる相手を探し始めた。カナダは話がまとまった。

## 料金
- 財布型のゲームは1作15ドル（約2,250円）。拡張もすべて1ドル（約150円）値上げした。5年以上ぶりの値上げで、関税と費用の高まりを理由に挙げている。
- 関税は30％のほか、10％や154％の時期もあり、1年ほどは値段に乗せずにしのいだ。
- クラファンでの予約は1作10ドル（約1,500円）、拡張と合わせても最大14ドル（約2,100円）。
- 募集の間は、公式の店で使える15％引きの割引を配る。
- ニュージャージー州の店では、どの作品も10ドル（約1,500円）。

## 時間順の流れ
- 2007年：Button Shy の名で、ボードゲームとカードゲームの自主出版を始める。
- 2013年10月：自主出版の失敗を語る登壇を案内する（催しは10月31日〜11月3日）。
- 2014年9月：財布型のケースに入れた Movie Plotz をクラファンで出す。
- 2015年1月：財布型シリーズの2作目 Pretense の募集を始める。目標は500ドル（約7.5万円）。
- 2024年1月：毎月1作の新作を出し、すべて手で組み立てている。
- 2026年4月：新作4本をまとめた春のクラファンを始める。主力を量産の箱入りに変え、18枚のシリーズは3か月ごとの募集にする。
- 2026年5月：ニュージャージー州の事務所は6人。うち3人が、社内で作る新しい種類のゲームを手がけていると紹介する。
