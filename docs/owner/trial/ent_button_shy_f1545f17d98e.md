# Button Shy

## 一覧の1行
カード18枚を財布ほどの袋に詰め、毎月1作ずつ手で組んで出し続け、新作4本の募集で約1,430万円を集めるまでになった、ポケットに入るカードゲーム

## 概要
Button Shy は、カード18枚だけで遊べる小さなボードゲームを出している、アメリカ・ニュージャージー州の出版社。ゲームはビニールの財布のような袋に入っていて、ポケットに入れて持ち歩ける。看板の Sprawlopolis では、1〜4人が手札を1枚ずつ置き、協力して街を作る。1回15〜20分で遊べる。

ゲーム作家のジェイソン・タグマイアが、2007年から Button Shy の名前で自分のゲームを出してきた。2014年に、財布型の袋に入れた1作目 Movie Plotz をクラウドファンディングで出した。その後は新作を毎月出すようになり、自分の店とクラウドファンディングで売っている。2026年春に新作4本をまとめて募集し、2,661人から95,245ドル（約1,430万円）を集めた。

## 成功の秘訣
1. **財布型の袋なら、少ない部数でもゲームを出せると気づいた**
   小さなゲームは包装に費用がかかり、少ない部数で出すのはふつう割に合わない。カードと説明書が収まる袋にしたことで、1作500個未満でも出せるようになった。
2. **問屋を通さず、客へ直接届ける道を選んだ**
   多くの出版社は問屋を通して店に並べる。Button Shy は作るところから売るところまで自分たちで行い、届け方まで自分の思い通りにした。
3. **ほかの作り手のゲームも、同じ袋に入れて出した**
   2作目を出す時、財布型のゲームを作りたい作り手に声をかけた。看板の Sprawlopolis も、ほかの3人の作り手によるゲームだ。

## 実際にやったこと
- 2014年9月、Movie Plotz の募集を始めた。目標の1,000ドル（約15万円）は、袋と折りたたみの説明書を作る費用に充てる額だった。
- 募集は初日に目標の約25％、2日目に約35％まで進み、そこで伸びが止まった。
- 3日目、ゲームの中で生まれた架空の映画を猫のポスターにして投稿すると、数時間で支援が倍になった。同じ朝に約800人へ便りも送っていた。本人は、どちらが効いたかは分からないと書いている。
- ボードゲームの情報サイト BoardGameGeek に、小さなゲームの包み方の記事を出した。反応は多かったが、支援の増加にはつながらなかった。
- 2015年1月、2作目の Pretense を目標500ドル（約75,000円）で募集した。絵は、以前に別の仕事で組んだフランスの画家に頼んだ。
- Pretense の募集では、それまでのカードゲームとのセットも用意した。全部をまとめて買うと、Pretense が実質ただになった。
- 毎月の新作を、1つずつ手で組み立てて出していた。
- Sprawlopolis には、海辺・高速道路・怪獣などの拡張カードを足して売っている。
- 毎月ゲームが届く会員制の集まりを、Patreon で運営している。
- 2026年、手で組み立てていた時間をゲーム作りに回した。社内の3人で新しいゲームを作る組を立ち上げ、本人は「もっと早く変えればよかった」と振り返った。

## つまずきと立て直し
- 2013年の登壇で、自分で出版した時の失敗を語った。募集で目標を超えて集まったのに、届ける費用が足りなかった。絵の仕上がりが遅れたこともあった。
- 規模が大きくなると、手で組む作業に時間を取られた。箱が無いと置いてもらえない売り場もあった。2026年、主力のシリーズを工場で量産する箱入りに切り替えた。
- 財布型を好む客もいたため、空の財布を追加の品として売ることにした。箱は、財布ごと入る大きさにした。
- 海外への送料が上がり続け、EU では荷物がまとめて送り返された。この損失は約500ドル（約75,000円）になった。
- 海外への直送は地域を絞り、現地の提携先を探し始めた。カナダは提携が決まった。
- 春の募集では送料として1万7,000ドル（約255万円）を預かっていたが、直後に海外の送料が8％上がった。
- 関税が30％かかるようになり、1年は値上げせずに耐えたが、続けられないと判断した。

## 料金
- 財布型のゲームは15ドル（約2,250円）に上げた。拡張は1ドル（約150円）ずつ上げた。5年以上ぶりの値上げだった。
- クラウドファンディングでの予約は、ゲーム1本10ドル（約1,500円）、拡張付きでも最大14ドル（約2,100円）。
- 募集の期間中は、公式サイトで使える15％引きの割引券を配る。
- 会員制の集まりでは、毎月のゲームに加えて割引券も受け取れる。
- ニュージャージー州の店では、どのゲームも10ドル（約1,500円）。
- 公式サイトを日本から見ると、Sprawlopolis は2,500円と表示される。

## 時間順の流れ
- 2007年：Button Shy の名前で、ボードゲームとカードゲームを自分で出版し始める。
- 2013年：自分で出版した時の失敗を、催しの登壇で語る。
- 2014年9月：財布型の1作目 Movie Plotz を募集する。
- 2015年1月：財布型の2作目 Pretense を募集する。
- 2024年1月：毎月の新作を、すべて手で組み立てて出している。
- 2026年4〜5月：主力を箱入りに変えて、新作4本をまとめて募集する。主力は年4回の募集に切り替える。
- 2026年5月：事務所は6人になり、社内の3人でゲームを作る組を立ち上げる。
