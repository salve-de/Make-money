# Button Shy

## 一覧の1行
小さなビニールの財布に18枚ほどのカードを詰めて毎月新作を出し、新作4作のクラウドファンディングで約1,430万円を集めた、ポケットに入るカードゲーム

## 概要
Button Shy は、小さなビニールの財布に、18枚ほどのカードと説明書を収めたカードゲームを出すアメリカの小さな出版社。ポケットに入れて持ち歩き、出先でも遊べる。看板作の Sprawlopolis では、1〜4人が手札を1枚ずつ出し合い、協力して街を作る。1回15〜20分で遊べる。

ゲーム作家のジェイソン・タグマイアが、2007年から Button Shy の名で自分のゲームを出してきた。2014年に、財布型の1作目をクラウドファンディングで募った。問屋を通さず、客へ直接売っている。ほかの作家の作品も加えて毎月1作ずつ新作を出し、1つずつ手で組んできた。2026年春には新作4作をまとめて募集し、2,661人から9万5,245ドル（約1,430万円）を集めた。

## 成功の秘訣
1. **少ない部数でも、財布に詰めれば出せると気づいた**
   ボードゲームを少しだけ作るのは、ふつうは割に合わない。財布型なら1作500個未満でも作れた。
2. **問屋を通さず、客に直接売ることにこだわった**
   多くの出版社は問屋を通して店に置く。Button Shy は何もかも自分たちで手がけ、思いどおりに仕上げることを大事にした。
3. **新作を毎月出し、会員の郵便受けに届けた**
   毎月1作のペースを守り、新作が届く会員の集まりを、会費制の支援サイト Patreon で作った。

## 実際にやったこと
- 2014年9月、財布型の1作目 Movie Plotz をクラウドファンディングで募集した。目標は財布と折りたたみ説明書を作る費用の1,000ドル（約15万円）だけだった。
- 募集は1日目に目標の約25％、2日目に約35％までしか進まなかった。3日目、遊んだ時に生まれた「猫が主役の架空の映画」のポスターを投稿すると、数時間で支援が倍になった。同じ朝に約800人へ便りも送っていたため、どちらが効いたかは本人にも分からない。
- 2日目までに、ボードゲームの情報サイト BoardGameGeek に、小さなゲームの包み方の記事を書いた。反応は集めたが、支援には結び付かなかった。
- 2015年1月、財布型の2作目 Pretense を目標500ドル（約7.5万円）で募集した。旧作と組み合わせて割り引き、全部をまとめて買うと Pretense が実質無料になるようにした。
- ほかのゲーム作家に、財布型の作品を作らないかと呼びかけた。看板作の Sprawlopolis は、Steven Aramini、Danny Devine、Paul Kluka の3人の作品。
- 基本のゲームに加えて、カード数枚の拡張を別売りにした。
- 2026年5月時点で、ニュージャージー州の事務所に6人がいる。絵と図案は社外の2人に任せている。

## つまずきと立て直し
- 2013年の講演の案内で、本人は自主出版での失敗を挙げた。絵の制作が遅れたことと、募集で目標を大きく超えたのに、品物を届けるお金が足りなくなったことだ。
- 手で組む作業に時間を取られ、箱が無いと売りにくい売り場もあった。2026年、主力を量産の箱入りに切り替えた。
- 財布を惜しむ客のために、空の財布を追加品として売り、箱は財布ごと収まる大きさにした。
- 切り替え後、手で組んでいた時間をゲーム作りに回せるようになった。本人は、もっと早く変えればよかったと振り返っている。
- 海外への送料が上がり続けた。ある募集で送料を1万7,000ドル（約255万円）集めた直後に、翌週から8％上がると決まった。
- EU など、輸入の要件が厳しくなった地域もある。国境で拒否された荷物がまとめて戻り、約500ドル（約7.5万円）を失った。海外への直送を絞り、各地で売ってくれる相手を探し始めた。カナダは話がまとまった。

## 料金
- 財布型のゲームは1作15ドル（約2,250円）。5年以上据え置いた後、30％の関税などを理由に値上げした。拡張も1ドル（約150円）ずつ上げた。
- クラウドファンディングで予約すると1作10ドル（約1,500円）で、拡張付きでも最大14ドル（約2,100円）。
- 募集の期間中は、公式サイトで15％引きの割引コードを配る。
- ニュージャージー州の店では、どのゲームも10ドル（約1,500円）。

## 時間順の流れ
- 2007年：Button Shy の名で、ボードゲームとカードゲームの自主出版を始める。
- 2013年10月：自主出版の失敗を語る講演の予定を告知する。
- 2014年9月：財布型の1作目 Movie Plotz を募集する。猫の映画のポスターを投稿した日に支援が倍になる。
- 2015年1月：財布型の2作目 Pretense を募集する。
- 2024年1月：毎月1作の新作を出し、すべて手で組んでいる。
- 2026年：手で組むのをやめ、主力を量産の箱入りに変える。
- 2026年4〜5月：春の新作4作（Astro ROVE、The Rise Of A Jarl、Everything Machine、Shaper）を募集する。
- 2026年5月：社内でゲームを作る3人の担当を紹介する。
