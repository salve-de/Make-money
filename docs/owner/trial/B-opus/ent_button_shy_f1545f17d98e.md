# Button Shy

## 一覧の1行
問屋を通さず客へ直接売り、新作を毎月1つずつ手で組んで出してきた、2026年春の募集で約1,430万円を集めるまでになった小さなカードゲーム

## 概要
Button Shy は、ポケットに入る小さなカードゲームを作って売る、アメリカ・ニュージャージー州の出版社。1作は12〜20枚のカードと説明書を、財布ほどのビニールケースに入れて販売する。代表作の Sprawlopolis では、1〜4人が協力して街を作る。

ゲーム作家 Jason Tagmire が2007年から Button Shy の名前で自主出版を始め、2014年に初めて Kickstarter で募集した。以来、小型で手に入れやすいゲームとして支援を集め、2026年春には4作をまとめた募集で2,661人から95,245ドル（約1,430万円）を集めた。

## 成功の秘訣
1. **カードの枚数と包装を絞り、少ない部数でも作れる形にした**
   小部数のボードゲームはふつう採算が合わない。カード12〜20枚と説明書だけを財布型のケースに収める形なら、500個未満でも製作可能だった。
2. **問屋を通さず、客へ直接売ることにした**
   多くの出版社は問屋を通して店に卸す。Button Shy はすべて自分たちで手がけ、思いどおりの形で客に届けることを選んだ。
3. **形を決めてから、外の作家にもゲームを作ってもらった**
   この形でゲームを作りたい作家を公に募った。代表作の Sprawlopolis も、社外の作家が作ったゲームだ。

## 実際にやったこと
- 2014年9月、Movie Plotz の募集を始めた。目標の1,000ドル（約15万円）は、財布型の包装と折りたたみの説明書を量産する費用に充てるものだった。
- 支援は初日に目標の約25％、2日目に約35％までしか進まなかった。
- 3日目、遊んだ場で生まれた架空の映画を、猫を使ったポスターにして投稿した。数時間で支援額は倍になった。同じ朝に約800人へ便りも送っており、どちらが効いたのかは本人にも分からない。
- ボードゲームの情報サイト BoardGameGeek に小型ゲームの包装について記事を書いた。反響と議論は呼んだが、支援の増加にはつながらなかった。
- 2015年1月に Pretense の募集を予告した。絵の代金は先に払い済みで、ケースと説明書とカードの製造費だけを集めるもので、目標を500ドル（約7万5,000円）に抑えた。
- 新作の募集で、旧作との組み合わせを割り引く予定を予告した。
- Patreon で、財布型のゲームが毎月届く会員制を始めた。
- 2026年、主力を箱入りに変えた。財布型を好む客には、空のケースを追加の品として売り、箱はケースごと収まる大きさにした。
- 箱の中では、図書館の目録カードに似た封筒にカードを入れた。
- 2026年春の募集は4作をまとめて出した。告知の短い枠では1作ずつの魅力を伝えにくい、と本人は書いている。
- 2026年5月の時点で、ニュージャージーの事務所に6人がいる。本人と George、Andrew Basile の3人が社内でゲームを作り、絵と図案は社外の2人が担う。
- 手で組む作業に使っていた時間を、ゲームを作る時間に回した。本人は「もっと早く変えればよかった」と振り返っている。
- 社内では小規模な実験的シリーズを企画している。サイコロなどは客が用意し、包装はなく、説明書はオンラインに置く。

## つまずきと立て直し
- 2013年までの自主出版では、絵の遅れに苦しんだ。募集で目標を上回る支援を集めても、届けるお金が足りなくなったこともある。
- 関税が変わり、1年ほど自社で負担した。値上げはその後になった。
- 海外への送料が上がり続けた。8％上がる直前に、ある募集で送料として17,000ドル（約255万円）を集めていた。
- EU では荷物が国境でまとめて差し戻され、約500ドル（約7万5,000円）を失った。
- 海外への直送を絞り、各地で届けてくれる提携先を探した。カナダは確定した。会員へ毎月届ける期限と社員の給与があるため、海外の話がまとまるのを待たずにアメリカでの販売を進めた。
- 手で組む作業が時間を食い、箱が無いと売りにくい市場もあった。量産の箱に変えて、規模に合う作り方にした。
- 主力の18枚のシリーズは、季節ごとの年4回の募集に変えた。

## 料金
- 財布型の1作は15ドル（約2,250円）。拡張はそれぞれ1ドル（約150円）上げた。5年以上ぶりの値上げだった。
- 募集での予約は、拡張込みでも最大14ドル（約2,100円）。
- 募集の期間中は、公式サイトで使える15％引きの割引コードを配る。
- ブラックフライデーには25％引きの割引コードを出す。
- 毎月届く会員制はアメリカだけで、イギリスは試しに始めている。

## 時間順の流れ
- 2007年：Button Shy の名前で、ボードゲームとカードゲームの自主出版を始める。
- 2014年9月：Movie Plotz の募集で、猫のポスターを投稿する。
- 2015年1月：Pretense の募集を予告する。
- 2024年1月：新作を毎月出し、すべて手で組んでいる。
- 2026年：主力を箱入りに変える。
- 2026年4〜5月：4作をまとめた春の募集を行う。
- 2026年5月：小規模な実験的シリーズを企画する。
