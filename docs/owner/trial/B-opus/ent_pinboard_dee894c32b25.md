# Pinboard

## 一覧の1行
大手 Yahoo の無料ブックマークサイトが「終わるらしい」と漏れた日に乗り換え客が押し寄せ、1人の運営で最も多い年に約3,900万円を売り上げた、有料のブックマーク保存サービス

## 概要
Pinboard は、ネットで見つけたページを自分用に取っておくサービス。ブラウザのボタンを押すと、読んだページを保存できる。保存のときにタグと短いメモを付けておけば、何か月も後に検索で見つけ直せる。料金を上乗せすると、保存したページの写しも残る。元のページが消えても読め、PDF の中身まで検索できる。広告も、利用者を追う仕組みも無い。

作ったのは、元 Yahoo Brickhouse の開発者、Maciej Cegłowski。Delicious の作り直しに不満を持ち、2009年春に自分用に作った。同じ年の7月に、ルーマニアのボトシャニで有料で公開した。2010年12月、Delicious を畳む可能性があると Yahoo の社内資料から漏れ、利用者が一気に移ってきた。数週間前まで数千人だった利用者は、月末には1万6,000人になった。運営は、ほぼ本人1人でこなしている。

## 成功の秘訣
1. **大手が作り直しで捨てた良さを、そのまま残した**
   Delicious の作り直しで使いやすさが失われ、本人の設計で素のままの道具を求める人が移ってきた。
2. **無料が当たり前の時代に、払う客だけを相手にした**
   料金で、運営の費用と本人の給料をまかなう。「伸びるか死ぬか」で動く無料のサイトは消えやすいので、払う方が長く続き、預けた記録も売られないと説いた。
3. **大手のつまずきが、そのまま自分の客になると見積もっていた**
   本人は、Yahoo の経営陣が悪い判断を重ねて、自分たちの市場を作ってくれたと振り返っている。乗り換えの波が来るたびに、受け皿として名前が挙がった。
4. **小さくても熱心な集まりの声を聞いた**
   ファンが書いた小説を集めて整理する人たちが、Delicious の作り直しで困っていた。その声を聞いて欲しい機能を尋ね、細かい要望に応えた。

## 実際にやったこと
- 2009年6月に試す人を募り、7月から有料の受付を始めた。
- Delicious の創業者の1人、Peter Gadjokov を誘い、技術面を手伝ってもらった。
- Delicious からの記録の取り込みを、ボタン1つでできるようにした。
- 2010年の大量流入の数か月前、別に運営するトコジラミ情報のサイトが CNN に載り、アクセスの急増で落ちた。それを機に、サーバーの余力を大きく増やしていた。Pinboard も同じサーバーで動いていたので、流入の日も落ちずにすんだ。
- 流入の日、本人は問い合わせのメールに次々と答えた。Gadjokov と2人でサーバーの設定を直し、重い機能は一時止めたり遅くしたりして乗り切った。
- 2011年、Delicious が別の会社に売られた。ファンの集まりが、作り直しで「/」が使えなくなったことに困っていた。この記号で登場人物の組み合わせを表していた。本人は Twitter で「Pinboard は / やほぼどんな文字でも使える」と伝え、欲しい機能を尋ねた。返ってきたのは、目次付きで53ページの要望書だった。
- Twitter の投稿や、あとで読むアプリ Instapaper・Pocket に入れたリンクを、自動で取り込めるようにした。
- Delicious の外部連携の仕組みと同じ形の窓口を用意し、他のアプリから使えるようにした。
- 2012年12月、小さく始める会社を応援する企画として、6社に37ドル（約5,550円）ずつと宣伝を約束した。
- 2017年6月、Delicious を3万5,000ドル（約525万円）で買い取った。新しい保存は受け付けず、利用者には記録の書き出しか Pinboard への移行を勧めた。
- 2020年、コロナ禍で家にいる間に、古い PHP と MySQL のコードを新しい版に移した。日本にいたので、欧米の客が寝ている夜に作業した。
- 2025年1月、贈り物用のアカウントを売り出した。
- Time は「1人の会社でも大企業と張り合える」と書いた。The Economist は「どこかで下着姿のまま、サーバーの画面を5つ開いている男1人」と書いた。

## つまずきと立て直し
- 2016年11月から、本人が米大統領選の後に技術者を組織する活動で各地を回った。問い合わせのメールを何週間も放っておくことがあり、怒りのメールがたまった。2017年の数か月は運営に戻り、サイトを安定させ、1人で見張りやすくした。
- 2018年は選挙の資金集めに時間を使い、客の不満が募った。活発な利用者は2017年の2万9,000人から2018年に2万1,000人、2019年に1万9,000人まで減った。本人は、離れた客を取り戻そうとしていると書いている。
- X（旧 Twitter）が外部連携の料金を大きく上げたため、投稿のリンクの自動取り込みの費用が高騰した。代わりに Bluesky との連携を、利用者の意見を聞きながら考えている。
- 2024年ごろから、中国発の多いロボットの大量アクセスに悩まされた。サイトを守るため、一部の公開ページをログインした人だけに絞った。2025年1月に簡単な人間確認の仕組みを入れ、公開ページを戻した。

## 料金
- 2009年7月の公開時：1回払いの登録料が約3ドル（約450円）。利用者が1人増えるたびに0.1セント（約0.15円）ずつ上がる。早く入った人ほど安く、迷惑な投稿をする人も入りにくくなる。
- 2010年1月ごろ：登録料は5.79ドル（約870円）。ページの写しを残す上乗せは年25ドル（約3,750円）。
- 2010年12月末：登録料は9ドル（約1,350円）まで上がった。
- 2015年1月：新しく入る人は、1回払いでなく年11ドル（約1,650円）に変わった。
- 2021年2月までに：年22ドル（約3,300円）、写しを残す上乗せ付きは年39ドル（約5,850円）に上がった。古い料金のままの利用者には、自分から切り替えるよう頼んだ。人を雇い、本人は新しい機能づくりに回るためと説明した。
- 今：年22ドル（約3,300円）から。何年分かまとめて払うと割引がある。無料のお試しは無いが、最初の1週間は理由を問わず全額を返す。

## 時間順の流れ
- 2009年春：Delicious の作り直しへの不満から、自分用に作る。
- 2009年7月9日：ルーマニアのボトシャニで公開し、有料の受付を始める。
- 2010年1月：利用者1,200人。本人の専業になる。
- 2010年：本人への取材から、この年の売上が11万7,000ドル（約1,755万円）だったことが分かっている。
- 2010年12月16日：Yahoo の社内資料から Delicious の終了が漏れ、登録が殺到する。
- 2011年9月：Delicious が別の会社に売られ、ファンの集まりが移ってくる。
- 2011年10月：登録2万5,000人、うち活発な利用者1万8,000人。
- 2015年1月：年額の料金に切り替える。
- 2017年6月：Delicious を買い取る。
- 2024年：保存されたブックマークは2億8,800万件。営業利益は年22万8,000ドル（約3,420万円）。
- 2025年1月：人間確認の仕組みを入れ、公開ページを戻す。贈り物用のアカウントを始める。
