## 何を書くか
読む人は「自分も稼ぎたい」人。その人が「こんなやり方で、こんなに取れるのか」と引き込まれ、開かずにいられない1〜2行（60字以内）を書く。『マーケットの魔術師』の目次のように、その事例の人物と戦い方が浮かぶ文にする。

- 主役は人物と戦い方。どんな人が、どんな場面で、何をして、誰のどんな痛みを取り、いくら取ったか。
- 場面が浮かぶ具体語を使う（「燃え尽きて旅に出た」「丸1日を失った」「30分のコードで」）。
- 何をする物かは一読で分かること。削りすぎて謎かけにしない。
- 締めは強い事実で言い切る（金額・人数・期間）。
- 事例ごとに個性を残す。全件を同じ型に押し込まない。

## 一読で「なるほど」になる関門（2026-10-08 オーナー了解。最優先）
読む人は、この1行で「なるほどね」となり、その下の文で詳しく分かる。だから1行だけで次の3つが伝わること。伝わらなければ、どれだけ引き込む文でも不合格。
1. **何の商売か**: 何を売り、誰の何の困りごとを解決するか。仕組みではなく、使う人が何をできるようになるかで書く（「管理ソフトを預かって動かす」ではなく「客先の機器管理を月額で請け負う」）。
2. **普通の言葉だけ**: 専門語・技術の説明・その分野を知らないと通じない言い方は使わない（拡張機能、ひな形、窓口が開いた、JavaScript を足す、継続売上など）。そういう説明はその下の文に回す。
3. **その会社自身の稼ぎ**: 締めの数字はその会社が得た金額・客の数・期間。客の成果（「解約が54%減」）では締めない。
- 文が絡まっていないこと。1行の中に、意味の分からない前置き（「ブログ広告が月6万円の頃」）や、誤解を生む並べ方（「初月4社から月3,750万円」）を入れない。
- それでも平坦な説明文にはしない。何の商売かは短く言い、残りで人物・場面・落差で引き込む。

試し方: 前提知識ゼロの人のつもりで1行だけを読み、「これは〇〇を売って〇〇円稼いだ話」と一言で言い返す。言い返せなければ不合格。

## 書かないもの
- 「〜に」「〜へ」で終わる「〜になった」型の締め（例: 「年1億円超に」）。
- 買収・売却。会社の結果で、どう稼いだかではない。
- 出資ゼロ・黒字・外部資金なし・「約500社を抱えた」のようなノイズ。
- 推定・推測の数字。リードに推定は出さない。確かな数字が無ければ、人数・期間・場面で勝負する。
- 本文に無い人物像・場面・数字。創作しない。
- 性別は本文に書いてある時だけ。分からなければ「開発者」「1人」「創業者」などで書く。

## 書く担当の手順
1. この紙と、事例の文（`data/case-pages/<事例ID>.md`）の全章を読む。
2. 本文から材料を拾う。人物（経歴・状況）、場面、取った痛み、たったこれだけ、の小ささ、確かな数字。「（推定）」「（推測）」の付いた数字は使わない。
3. 型の違う候補を3つ書く（例: 人物と場面で引く／落差で引く／痛みと金額で引く）。どの候補も「一読で『なるほど』になる関門」を満たすこと。本文の言い方が専門的なら、事実を変えずに普通の言葉へ言い換える。
4. 候補ごとに、使った事実と、それが本文のどの章のどの文にあるかを1行で添える。
5. 指定のファイルに保存する。事例の文そのものは直さない。

## 選ぶ担当の手順（書いた担当とは別の者がやる）
1. この紙と、事例の文と、候補のファイルを読む。
2. 候補ごとに、使った事実が本文に本当にあるかを確かめる（推定・推測の数字、創作が混じっていたら失格）。
3. 残った候補を、上の「何を書くか」「書かないもの」と、オーナーの例・判定に照らして比べる。読む人が開きたくなるか、何の話か一読で分かるか、締めが強いか。
4. 1つ選ぶ。言葉を少し直してよいが、事実は足さない。全部ダメなら「書き直し」とし、理由を書く。
5. 60字以内、「に／へ」で終わらない、買収・売却・推定が無いことを最後に確かめる。
6. 選んだ文を声に出して読むつもりで読み、引っかかる所が無いか確かめる（話し言葉の「やる・やり」、助詞の続き過ぎ、主語のねじれ）。あれば言葉を直す。
7. 「一読で『なるほど』になる関門」を、前提知識ゼロの人のつもりで試す。理由の行に「言い返し: これは〇〇を売って〇〇稼いだ話」を1行で書く。言い返せない候補は選ばない。

## 出力の形
書く担当（`docs/owner/lead-lines/<事例ID>.md`）:
```
## 候補1
<文>
- 使った事実: <事実> ／ 本文の場所: <章名>「<文の頭10字ほど>…」
## 候補2
…
```
選ぶ担当（同じファイルの末尾に足す）:
```
## 選んだ1行
<文>
- 理由: <1行>
```

- 報告は3行以内。保存先と、書き直しにした事例だけ。
