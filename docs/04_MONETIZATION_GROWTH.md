# 収益化・成長戦略

## 1. 価値の二層

### 無料で与えるもの

- 驚き
- 可能性
- 新しい稼ぎ方の発見
- 基本DB
- サービス無料掲載
- 限定保存
- 共有可能なカード

### 有料で売るもの

- 他人より早く知る
- 根拠を深く確認する
- 市場を継続監視する
- 複数候補を比較する
- 調査時間を減らす
- 自社への需要・購買意向を知る

## 2. 初期プラン仮説

### Free — ¥0

最新フィード、基本検索、限定保存、週刊ダイジェスト、無料掲載。

### Radar Pro — ¥1,980/月

全金脈、根拠詳細、保存・追跡無制限、比較、アラート、履歴、MY GOLDMINE分析。

### Research — ¥4,980/月

Pro、CSV、根拠履歴、市場マップ、チーム共有、匿名化された需要・Intent集計。

### Team / API

利用席、データ量、再配布範囲に応じた個別契約。

価格は確定値ではない。無料→詳細閲覧、保存上限、アラート利用の転換をテストして決める。

## 3. 掲載者課金

無料掲載を維持してDBの網羅性を確保する。有料機能は次へ限定する。

- 「プロモーション」表示付き配信
- 対象層へのベータ募集
- 詳細分析
- 問い合わせ・リード管理
- 動画、事例、FAQの拡張
- ニュースレター枠
- 再告知

有料でオーガニック順位、Evidence grade、Opportunity scoreを上げない。

## 4. 追加収益

- 開発・決済・ホスティング等の明示されたアフィリエイト
- 外部M&A・業者への送客
- データAPI
- 法人向けカスタムレポート
- スポンサー付きテーマレポート
- 許諾済みの匿名Intentデータ

## 5. 成長ループ

### 共有ループ

金額、人数、期間、根拠ランク、まだ入れる理由を画像カードにし、SNS・ブログ・ニュースレターへ共有する。

### 掲載ループ

掲載者が自分のページ、実績バッジ、ランキング、需要票を外部へ共有し、閲覧者が戻る。

### 需要ループ

需要投稿へ票が集まる → 制作者が現れる → ベータ利用者が集まる → 成果がMoney Signalになる。

### 発見者ループ

早期に登録した発掘者の実績が残る → 地位が生まれる → 新しい情報が投稿される。

### SEOループ

サービス、代替、価格、需要、成功事例、市場の時系列が構造化ページとして増える。

## 6. リテンション

再訪理由は「また面白い事例がある」だけでは弱い。次を組み合わせる。

- 保存市場の変化
- 新しいMoney Signal
- 競合増加・価格変更
- 需要票の増加
- 誰かが作り始めた通知
- 自分の掲載ページへの反応
- 週次の金脈ポートフォリオ変化

## 7. 初期集客順

1. 強い30–50件の金額付き事例カード
2. 検索意図がある比較・市場・成功事例ページ
3. 個人開発者への無料Claim案内
4. 公開コレクションと埋め込みカード
5. 週刊メール
6. 発掘者制度
7. 有料プロモーション

広告費を先に使うのではなく、共有される情報単位と掲載者流入を先に成立させる。
