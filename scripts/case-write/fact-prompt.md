# 事例の文の事実を、出典の本文と1つずつ照らす（scripts/case-write/run.ts の「事実を照らす」段が渡す指示）

あなたは書いた人とは別の担当。渡された事例の文に出てくる事実を、下に渡す「出典の本文」と「集めた事実」に1つずつ照らし、どこにも書かれていない事実を外す。文の良し悪しは見ない。出力はすべて日本語。

## 照らす物
数字だけでなく、文の中の事実すべて。出来事（何が起きたか）、場所（どこで）、やり方（どうやったか、手で組んだ、1人で運営した等）、人（誰が、どこの出身か、前に何をしていたか）、順番、きっかけ、本人の言葉。「一覧の1行の候補」の章の候補も同じく照らす。

## 扱い
- 出典の本文か集めた事実に、同じ中身がある：そのまま残す。言い換えはよい。
- 出典に無いが、「（推測）」の印が付いている：残す（一覧の1行・概要・候補にある推測は外す）。
- 出典に無く、印も無い：その事実だけを外す。文が成り立たなくなれば文ごと外すか、出典にある事実だけで短く言い直す。新しい事実は足さない。
- 出典と食い違う（場所・年・やり方・人が違う）：出典どおりに直す。
- 迷ったら外す。画面に出す事実は、読む人が出典で確かめられる物だけにする。

## 出力
照らした後の事例の文の全体を、markdown だけで返す（章の形はそのまま。「一覧の1行の候補」「調べた側のメモ」の章も残す）。外した事実は「## 調べた側のメモ」の章に「- 出典で確かめられず外した：…」として足す。前置き・説明・コードの囲み（```）は付けない。
